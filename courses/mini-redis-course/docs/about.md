# 课程介绍

这门课回答一个主线问题：

> **一个把全部数据放进内存的键值服务器，凭什么做到快、省内存、还不丢数据？**

输入是一句主题：「redis 解决了什么问题，redis 原理，怎么写一个 redis」。全书 11 章，前九章每章亲手做出一个零件，最后合起来就是一个能被真 redis-cli 连上、带 TTL、淘汰、AOF/RDB 持久化的迷你 Redis——companion 工程约 1300 行（不含空行），101 条测试全绿。它不是 Redis 的复刻：每一处与真货的不同都在正文当场声明，并汇总在[差异清单](./divergence)。

读者画像：会 TypeScript、用过数据库，没读过存储内部的开发者。不需要网络编程或多线程基础——需要的概念每一章都从零教起。

## 能力阶梯

- 学完第 1 章，你能用延迟数量级纸笔算清「为什么所有存储系统都拿内存当救兵」，并画出 cache-aside 读写时序、指出不一致窗口。
- 学完第 2 章，你能逐字节读写 RESP 帧，让本机 redis-cli 连上你自己写的服务器收发命令（半包粘包不再神秘）。
- 学完第 3 章，你能亲手复现并解释「一个不敲字的客户端冻结全场」，跑通十连问管道实验，讲清 select 到 epoll 的演进。
- 学完第 4 章，你手写了渐进式 rehash 的哈希表：灌十万键触发扩容，rehash 进行中 GET 依旧瞬回。
- 学完第 5 章，你实现了跳表与 ZADD/ZRANGE，一万随机分数与排序基准逐一对上，讲清抛硬币为什么免去全局再平衡。
- 学完第 6 章，你实现了惰性加定期两路过期删除，能解释验证码内存翻三倍之谜。
- 学完第 7 章，你实现了随机抽样近似 LRU 与 noeviction/allkeys-lru，亲手复现 OOM 拒写并腾位。
- 学完第 8 章，你实现了 AOF 追加、重放与重写瘦身——「重启」后数据真的回来了。
- 学完第 9 章，你实现了 RDB 快照的拍—砸—装往返，能跟算 fork 与写时复制的账。
- 学完第 10 章，你能推演主从全量同步三阶段、算 backlog 补发与 16384 槽的归属（视野章，不进 mini）。
- 学完第 11 章，你能把全书收成四问四答，指着文件与测试讲清 mini 的每一层。

## 怎么跑

- 聚合入口：仓库根 `pnpm dev`，从课程中心进入本课。
- 单课预览：`cd courses/mini-redis-course && pnpm install && pnpm docs:dev`。
- 验证物工程：`cd companion && npm install && npm test`——101 条测试；`node src/boot.ts` 起服务器，`redis-cli -p 6399` 连它。
