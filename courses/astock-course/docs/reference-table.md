# 速查表：费率、规则与公式

> 本课程内容仅用于学习交流，不构成任何投资建议。下表为课程写作时点的口径（2026-09 核对），若已修订以交易所与财政部等最新公告为准。

## 交易费用（沪深 A 股）

| 费用 | 收取方 | 方向 | 费率 | 生效/口径 |
| --- | --- | --- | --- | --- |
| 佣金 | 券商 | 买卖双向 | 课程示例：万分之 2.5，单笔不足 5 元按 5 元收（实际以开户合同为准，可协商） | 随券商 |
| 印花税 | 国家（税务） | 仅卖出单边 | 卖出金额 × 万分之 5（0.05%） | 2023-08-28 起（财政部 税务总局公告 2023 年第 39 号） |
| 过户费 | 中国结算 | 买卖双向 | 成交金额 × 万分之 0.1（0.001%） | 2022-04-29 起 |

**完整成本 = 买入佣金 + 买入过户费 + 卖出佣金 + 卖出过户费 + 卖出印花税**（第 3 章五笔账）。

## 交易规则

| 项目 | 规则 |
| --- | --- |
| 交易时段 | 开盘集合竞价 9:15–9:25（9:20–9:25 不可撤单）；连续竞价 9:30–11:30、13:00–14:57；收盘集合竞价 14:57–15:00 |
| 交易日分界 | 15:00 收盘：之前下单算当日（T），之后算下一个交易日 |
| T+1 | 当日买入的股票，次一交易日才能卖出；当日卖出资金当日可用、次日可取 |
| 涨跌幅限制 | 主板 ±10%（含 ST、*ST，2026-07-06 起统一）；创业板、科创板 ±20%；北交所 ±30% |
| 新股上市初期 | 主板、创业板、科创板前 5 个交易日不设涨跌幅 |
| 最小交易单位 | 主板、创业板 1 手 = 100 股；科创板单笔申报不低于 200 股，超出部分按 1 股递增 |
| 涨跌停价 | 前收盘 ×（1 ± 幅度），四舍五入到 0.01 元 |
| 盘后固定价格交易 | 15:05–15:30，以收盘价成交（2026-07-06 起扩展至全部 A 股与沪深 ETF） |
| ETF 交易 | 场内按市价买卖（有折溢价），受涨跌停板约束；基金份额买卖免印花税 |

## 判定与公式

| 名称 | 公式 / 判定式 | 出处 |
| --- | --- | --- |
| 终值（复利） | 终值 = 本金 ×（1 + 收益率）^年数 | 第 1 章 |
| 实际收益率（近似） | 实际收益率 ≈ 名义收益率 − 通胀率 | 第 1 章（精确式见差异清单） |
| 收益率 | 收益率 =（期末 − 期初）÷ 期初；跨年限比较先年化 | 第 1 章 |
| 市盈率 | PE = 股价 ÷ 每股盈利（课程按最近年报净利润的静态口径） | 第 7 章 |
| 盈利收益率 | 盈利收益率 = 1 ÷ PE = 每股盈利 ÷ 股价 | 第 7 章 |
| 贵贱判定（粗筛） | 盈利收益率 ≥ 一年期存款挂牌利率 → 不输存款；< → 贵得危险（判定前查最新挂牌利率） | 第 7 章 |
| 股息率 | 股息率 = 每股分红 ÷ 股价 | 第 7 章 |
| 回本涨幅 | 回本涨幅 = 亏损幅度 ÷（1 − 亏损幅度） | 第 9 章 |
| 最大回撤 | 最大回撤 =（峰值 − 谷值）÷ 峰值 | 第 9 章 |
| 波动率（课程口径） | 月收益率标准差 × √12 年化 | 第 9 章（简化口径见差异清单） |
| 单笔可买数量 | 可买数量 =（总资金 × 单笔风险预算）÷（买入价 − 止损价），按手取整 | 第 11 章 |
| 定投平均成本 | 平均成本 = 总投入 ÷ 累计份额 | 第 11 章 |
| 再平衡 | 总资产 × 目标比例 − 当前仓位金额 = 调仓额（卖超配、买低配） | 第 10 章 |

## 七步研究清单（速记）

①生意（钱从哪来）→ ②护城河（十年之问）→ ③财报体检（五项指标）→ ④估值（倍数 + 七折线）→ ⑤趋势与位置（描述不预测）→ ⑥风险与仓位（先定输多少）→ ⑦决策（买 / 不买 / 观察 + 推翻条件）。每步带不通过出口，任一步不通过即放弃或降级观察（第 14 章）。

## 一页纸计划书（六槽）

①目标（有数字与期限）→ ②配置（股债比例）→ ③买入规则（触发条件）→ ④卖出规则（非成本价触发）→ ⑤风控红线（具体数值）→ ⑥复盘节奏（日期 + 对账单）。每槽可判定，操作前对照，冲突不做（第 15 章）。
