# 术语表

全书 71 个术语，按首教顺序排列；「定义」是它是什么，「接口」是怎么用（接口收在各章正文与「工具箱」槽）。回查正文可用站内搜索。

| 术语 | 英文 | 它是什么 |
| --- | --- | --- |
| 货币时间价值 | time value of money | 今天的一笔钱比未来的同额更值钱，因为它能立刻投入增值，等待本身有代价。 |
| 复利 | compound interest | 每期收益并入本金一起再生收益，增长按指数曲线进行而非直线。 |
| 通货膨胀 | inflation | 整体物价水平持续上涨，同样的金额能买到的东西逐年变少。 |
| 实际购买力 | real purchasing power | 名义金额经物价折算后真正能买到的商品与服务数量。 |
| 收益率 | return | 期末相对期初增长的百分比，衡量一笔钱的增值速度。 |
| 股票 | stock | 公司所有权的一份凭证，持有一股就按比例拥有公司的一份。 |
| 股权 | equity | 对公司资产与利润的剩余索取权，公司还清一切欠账后剩下的都归股东。 |
| 市值 | market capitalization | 股价乘以总股本，是市场给公司全部股权开出的总标价。 |
| 盈利 | earnings | 公司一段时期赚到的净利润，长期股价最重要的锚。 |
| 估值 | valuation | 市场价格相对基本面（盈利、净资产）的倍数关系，即市场情绪给基本面的放大倍数。 |
| 集合竞价 | call auction | 把一段时间内的买卖申报集中起来，按最大成交量原则一次性撮合出唯一成交价。 |
| T+1 | T+1 | 当日买入的股票，次一交易日才能卖出（现行载体为沪深交易所《交易规则》；1998 年版《证券法》第 106 条为其历史源头，2005 年修订后删除）——当日卖出所得资金当日可用、次日可取。 |
| 涨跌停板 | price limit | 以前收盘价为基准，限制当日报价的最大波动幅度，触及后价格当天不再超越该价位。 |
| 印花税 | securities stamp tax | 卖出股票时按成交金额的万分之5向卖方单边征收的税（2023-08-28 起，财政部 税务总局公告2023年第39号）。 |
| 佣金 | commission | 券商按成交金额收取的经纪服务费，买卖双向，费率可在开户时协商。 |
| 过户费 | transfer fee | 中国结算按成交金额的万分之0.1双向收取的股权登记过户费（2022-04-29 起）。 |
| 手 | lot | A股主板与创业板的最小交易单位，1手 = 100股。 |
| 交易日 | trading day | 交易所开市的日子，非节假日周一至周五；T 日、T+1 的「日」都指它。 |
| K线 | candlestick | 用矩形实体加上下影线，把一个周期的开盘价、收盘价、最高价、最低价画成一根蜡烛。 |
| 阳线与阴线 | bullish / bearish candle | 收盘价高于开盘价收阳线（A股红色），低于则收阴线（A股绿色）。 |
| 上影线与下影线 | upper / lower shadow | 实体上方/下方的细线，记录价格一度到达却没能守住的高点/低点。 |
| 成交量 | volume | 一个周期内成交的股数或金额，是价格运动的燃料。 |
| 均线 | moving average | 最近N个收盘价的算术平均连成的曲线，近似这段时间的平均持仓成本。 |
| 趋势 | trend | 价格运动的方向性：高点低点同时抬升为上升趋势，同时下移为下降趋势，交织为震荡。 |
| 支撑与压力 | support / resistance | 价格容易止跌的区域（支撑）与容易受阻的区域（压力），源于前期密集成交与套牢筹码。 |
| 金叉与死叉 | golden cross / death cross | 短期均线上穿长期均线为金叉，下穿为死叉，是趋势转换的滞后确认。 |
| 资产负债表 | balance sheet | 某一时点公司「有什么、欠什么、股东剩什么」的快照：资产 = 负债 + 所有者权益。 |
| 利润表 | income statement | 一段时期「赚没赚钱」的过程记录：收入减成本费用等于利润。 |
| 现金流量表 | cash flow statement | 一段时期真金白银流入流出的记录，分经营、投资、筹资三类。 |
| 营业收入 | revenue | 公司卖货或提供服务收进来的钱，未扣任何成本。 |
| 毛利率 | gross margin | 毛利除以营收，即卖价里超出直接成本的部分占比。 |
| 净利润 | net profit | 扣完一切成本、费用和税后剩下的利润，市盈率的分母。 |
| 应收账款 | accounts receivable | 货已发出、钱还没收到的部分，是记在账上的纸面收入。 |
| 货币资金 | cash and equivalents | 公司账上随时可动用的钱。 |
| 经营现金流 | operating cash flow | 主营业务实际收进减付出的净现金，是利润的「现金版」。 |
| 市盈率 | P/E ratio | 股价除以每股盈利（或市值除以净利润），按当前盈利水平多少年回本的倍数。 |
| 盈利收益率 | earnings yield | 市盈率的倒数：每一元股价每年赚回多少利润。 |
| 市净率 | P/B ratio | 股价除以每股净资产，价格相对账面家底的倍数。 |
| 股息 | dividend | 公司把一部分利润以现金形式分给股东。 |
| 股息率 | dividend yield | 每年每股分红除以股价，持有股票的年度现金回报率。 |
| 无风险利率 | risk-free rate | 不承担信用风险就能拿到的利率，课程用一年期定期存款挂牌利率作近似锚（2025-05-20 工农中建交五大行 0.95%、邮储 0.98%）。 |
| 内在价值 | intrinsic value | 公司未来能创造的全部现金折算到今天的合计，只能估算区间、不能精算到分。 |
| 安全边际 | margin of safety | 买入价低于估算内在价值的余量，为判断出错预留的缓冲垫。 |
| 能力圈 | circle of competence | 你真正能理解其生意与风险的公司边界，圈内决策、圈外认怂。 |
| 护城河 | moat | 让对手难以复制的结构性优势：品牌、网络效应、成本优势、牌照、转换成本。 |
| 波动率 | volatility | 价格围绕均值上下颠簸的剧烈程度，常用收益率标准差度量。 |
| 最大回撤 | max drawdown | 从历史最高点到其后最低点的最大跌幅，衡量最惨时刻。 |
| 盈亏不对称 | loss-gain asymmetry | 亏损与回本所需涨幅在百分比上不对称：亏50%需要涨100%才回本。 |
| 回本涨幅 | recovery gain | 从当前亏损状态回到成本价所需的上涨百分比。 |
| 分散化 | diversification | 把资金分布在低相关资产上，让任何单一灾难都不至于致命。 |
| 相关性 | correlation | 两个资产涨跌同步程度的度量，取值 −1 到 +1，越接近0互相抵消越强。 |
| 资产配置 | asset allocation | 决定各大类资产（股、债、现金等）比例的顶层设计。 |
| 再平衡 | rebalancing | 组合比例偏离目标后，卖出超配部分、买入低配部分，回到目标配置。 |
| 仓位 | position size | 已投入风险资产的资金占总资金的比例。 |
| 仓位管理 | position management | 按风险预算决定每笔投资金额的规则体系。 |
| 定投 | dollar-cost averaging | 固定时间间隔投入固定金额，用纪律摊平买入成本。 |
| 单笔风险预算 | per-trade risk budget | 愿意为单笔投资承受的最大亏损占总资金的比例，常见1%–2%。 |
| 损失厌恶 | loss aversion | 同额亏损带来的痛苦约为盈利快乐的两倍，导致该卖不卖、该买不买。 |
| 处置效应 | disposition effect | 盈利急着卖、亏损不肯卖的倾向，俗称卖盈持亏。 |
| 锚定效应 | anchoring | 把与价值无关的数字（自己的成本价、历史最高价）当成决策参照点。 |
| 从众效应 | herding | 跟随大多数人行动，结果往往在顶部接盘、底部割肉。 |
| 指数 | index | 按公开规则选出一篮子证券并加权计算的表现标尺。 |
| 宽基指数 | broad-based index | 覆盖全市场多行业的指数（如沪深300、中证500），不押注单一行业。 |
| 指数基金 | index fund | 以复制某指数表现为目标的基金，低费率、持仓透明。 |
| ETF | exchange-traded fund | 在交易所像股票一样按市价买卖的指数基金。 |
| 费率 | expense ratio | 基金每年从资产中扣除的管理与运作成本比例。 |
| 商业模式 | business model | 公司赚钱的方式：卖给谁、收什么钱、成本结构如何。 |
| 研究清单 | research checklist | 把分析流程固化为带出口的检查序列，防漏项、防情绪化。 |
| 投资体系 | investment system | 目标、配置、买卖规则、风控红线、复盘节奏的总和。 |
| 投资计划书 | investment policy statement | 把个人投资体系写成的一页纸契约。 |
| 熊市 | bear market | 市场整体长期下跌的阶段。 |
