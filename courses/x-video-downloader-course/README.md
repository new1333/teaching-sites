# X 视频下载插件：从零写一个真能用的浏览器扩展

一门动手课：从零写一个 Chrome/Edge（Manifest V3）浏览器插件，下载 X(Twitter) 上的视频。主线问题是「X 的视频，页面上是一串打不开的假地址、网络里是一把几秒的小分片——一个插件怎么把它变回你硬盘上的一个文件？」。

## 怎么跑

两条路：

- 项目根 `pnpm dev`，从聚合站进入本课程；
- 或在本目录 `pnpm install && pnpm docs:dev` 单独预览。

验证物工程（companion 目录本身就是可直接装载的扩展）：

```bash
cd companion && pnpm install
pnpm test              # 76 个测试全绿（纯逻辑 + 注入式假网络，不碰真实网络）
pnpm run typecheck     # tsc --noEmit（checkJs）
node scripts/audit-manifest.mjs   # 权限对账：10 项全对上号
pnpm run package       # 打出 dist/x-video-downloader.zip（两次运行逐字节一致）
```

装载扩展：chrome://extensions 打开开发者模式 →「加载已解压的扩展程序」→ 选 companion 目录本身。

## 环境要求与可感知性说明

- 代码侧验证（测试/类型/核对/打包）零输入可跑，不需要任何外部账号。
- 浏览器侧任务清单（各章「验证」小节）需要：Chrome 或 Edge、一个能登录 x.com 的账号、以及若干含视频的推文。这些现象类验证依赖真实环境，课程对每条都给了「应看到什么」的可判定描述；无法复现的环境（如 X 改版）已按时效口径给出现场核对步骤。

## 终点里程碑

一个装进 Chrome 就能用的 X 视频下载插件（零构建，929 行）——装载后点推文上的下载按钮，磁盘出现可播放视频文件；companion 内 typecheck + 76 测试全绿。
