# 关于本课程

> **X 的视频，页面上是一串打不开的假地址、网络里是一把几秒的小分片——一个插件怎么把它变回你硬盘上的一个文件？**

全书 7 章就是这句话的答案。课程从零写一个真能用的浏览器插件：companion 目录本身就是可直接装载进 Chrome 的 MV3 扩展，零构建、零运行时依赖，随章节逐章长大——第 1 章一个最小骨架（约 80 行），读完时 929 行，76 个测试全绿。

- **输入主题**：怎么写一个浏览器插件，下载 X(Twitter) 视频
- **读者画像**：会写现代 JS（async/await、fetch、DOM、ESM）、装过插件但没写过的开发者
- **终点**：一个装进 Chrome 就能用的 X 视频下载插件——点推文上的下载按钮，磁盘出现可播放文件

## 边界声明

本课程仅用于学习浏览器扩展开发：请只下载你拥有版权或已获明确授权的内容，遵守 X 服务条款与当地著作权法。

## 内容时效

X 的前端 DOM、内部接口与视频投递方式随版本变化（本课程内容截至 2026-08）。课程教的是标准协议（HLS/RFC 8216）与可迁移的插件开发方法；易变细节（选择器、URL 形态）正文随讲给出现场核对步骤，不为任何快照背书。浏览器 API 行为以 [developer.chrome.com](https://developer.chrome.com/docs/extensions) 为准。

## 能力阶梯

学完各章，你能：

| 章 | 你能做什么 |
| --- | --- |
| 1. MV3 插件的最小骨架 | 装载未打包扩展，分清 content script 与 service worker 两个世界各自能做什么 |
| 2. 让视频现形 | 在 DevTools 里同时看到假地址与真请求，让插件后台实时滚出 video.twimg.com 的播放列表地址 |
| 3. 拆开播放列表 | 逐行念出 m3u8 两级清单，写出按带宽选最高画质的解析器（测试全绿） |
| 4. 分片下载管线 | mp4 直链一行落盘；HLS 分片并发抓取、字节拼接，跨环境协作存出可播放的文件 |
| 5. 按钮上推文 | 滚动与路由后按钮自动出现，状态机走完全程，正式消息协议接通两个世界 |
| 6. 权限与发布 | 给 manifest 每项权限报出凭什么，跑通核对脚本并打出可上架的 zip |
| 7. 全链路对账 | 从点击到落盘每一跳报出环境、API 与凭什么非它不可 |
