# 关于本课

> **打开 Clash 之后，你的流量到底经历了什么？——亲手写一个 mini 版，让每一跳都变成自己的代码。**

这是全书的 driving question。十二个章节就是它的答案：从一块「系统代理」告示牌讲起，亲手写出 HTTP 代理、SOCKS5 入口、两跳中继、AEAD 加密隧道、规则引擎、fake-ip 电话簿、TUN 报文解析器、配置与代理组，最后总装成一条命令拉起的 `startMiniClash`。

## 课程由来

- 输入：主题句「clash 等代理软件的原理是什么，怎么手写一个」。
- 读者画像：会写 TypeScript、能跑命令行；TCP/HTTP 报文与对称加密/AEAD/哈希零基础（据开课校准问卷实测，问卷与默认见 `.course/calibration.json`）。
- 课程形态：原理重实现课 · code-lab 验证（TypeScript + Node.js 内建模块 + vitest）· 代码全展开 · 含合规边界声明（legal）。
- 全书 12 章，配套验证物工程 `companion/`：10 个源文件、约一千五百行、9 个测试文件 73 条用例全绿、9 个可跑 demo。

## 能力阶梯

学完第 N 章，你能……

- **1** 画出「入口/分流决策/出站隧道」三角色全景图；在本机回环亲手建立 TCP 连接，解释「命令行为什么连不上」。
- **2** 徒手读 HTTP 报文字节；写出能听懂 absolute-form 与 CONNECT 的 HTTP 正向代理。
- **3** 按 RFC 1928 的字节表写出 SOCKS5 服务端；用累积缓冲与状态机接住「半个消息」。
- **4** 把链路升级为「入口→远端→目标」两跳，设计长度前缀帧并双向中继。
- **5** 说清加密防的三件事；亲手复现「只加密不认证被定点篡改」与「同 nonce 复用异或泄露」。
- **6** 实现盐 + HKDF + 长度前缀 AEAD 块的加密隧道，与 Shadowsocks 公开规范对表。
- **7** 写出按序首中即停的规则引擎（五种形态、CIDR 按位与），入口按判决分流。
- **8** 实现最小 UDP DNS 应答器与 fake-ip 池；解释污染、泄露与「假门牌反而是收益」。
- **9** 逐字段解析 IP/TCP 头部，按五元组把一包包字节还原成连接。
- **10** 用 JSON 声明式配置驱动整机；实现 select 与 url-test 代理组（延迟探测掐表到首字节）。
- **11** 一条命令拉起整机：域名 → 假门牌 → 还原 → 判决 → 组 → 加密隧道 → 远端 → 目标，端到端跑通。
- **12** 对外完整讲出「打开 Clash 之后流量经历了什么」，并按差异地图看懂真实 Clash 还有什么。

## 边界与时效

- 本课程内容仅用于学习网络协议原理。代理与隧道技术在不同司法辖区受不同法规约束；全部实验在本机回环完成，课程不提供任何真实节点或订阅信息——请在遵守当地法律法规的前提下学习。
- 协议事实以课程权威文档清单为准（RFC 9110/9112、RFC 1928、RFC 5869、NIST SP 800-38D、RFC 1035、RFC 791、RFC 9293、Node.js 官方文档、Shadowsocks AEAD 公开规范、Clash 公开文档）；教学实现与真实实现的全部差异见[差异清单](./divergence)。
