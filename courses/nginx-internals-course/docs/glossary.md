# 术语表

全书术语按首现顺序收录，定义就是正文首现时那句人话——忘了哪个词，回这里查。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 并发连接数 | concurrent connections | 同一时刻挂在服务器上的「通话中」数量，不是每秒新来电数 |
| C10K 问题 | C10K problem | 一台服务器同时伺候一万个连接这道经典难题 |
| 套接字 | socket | 程序世界里的一部电话机——应用程序通过它接进网络打电话 |
| 文件描述符 | file descriptor | 操作系统发给每个「电话机」的编号凭条 |
| 阻塞 I/O | blocking I/O | 打电话时占着人死等对方开口，别的什么都干不了 |
| 非阻塞 I/O | non-blocking I/O | 不占人死等——留一句「有消息叫我」，自己继续干别的 |
| 事件多路复用 | I/O multiplexing | 雇一位传达室大爷同时盯一万个门铃，谁响了叫谁来取 |
| epoll | — | Linux 提供的那位「传达室大爷」的官方名字 |
| 事件循环 | event loop | 不断重复「等事件→处理事件」的循环，服务器的心跳 |
| 回调 | callback | 留给系统的一句留言：「事来了打这个电话」 |
| TCP 连接 | TCP connection | 两个程序之间拨通的通话线路，保证字节按序完整到达 |
| 字节流 | byte stream | 数据在网络里像水管的水，一股股涌出来，天生不分「一封一封」 |
| 粘包与半包 | — | 一次到货粘了两条消息 / 一条消息只到一半——水管流水的常态 |
| 状态机 | state machine | 给解析器画的一张「读到哪了」地图，每读一段就知道下一步去哪 |
| keep-alive | — | 说完一件事不挂电话，接着说下一件 |
| TIME_WAIT | — | 主动挂电话的一方要原地多等一会儿才能走，防止最后的告别没送到 |
| 内存分配器 | malloc | 操作系统的「给我一块内存 / 我还一块内存」服务，每次记账都有成本 |
| 内存碎片 | fragmentation | 反复进货退货后，仓库里到处是塞不进大件的小空格 |
| 内存池 | memory pool | 整批进货再零售的仓库；清仓时整仓清空，不用一件件对账 |
| 配置上下文 | context | nginx.conf 里一层层的花括号房间，指令写在哪个房间就算哪个房间的 |
| 配置继承 | inheritance | 房间没写的规矩沿用外面大房间的；写了就自己说了算 |
| master 进程 | — | 只管不接待的老板：读配置、盯员工、收指令，不亲自伺候连接 |
| worker 进程 | — | 真正伺候客人的员工，一人一摊互不打扰，倒了一个老板再招一个 |
| 信号 | signal | 操作系统层面发给进程的对讲机暗号 |
| 优雅关闭 | graceful shutdown | 「不再接新客，把手头客人送完再下班」 |
| 热升级 | hot upgrade | 换发动机不熄火——新二进制顶上，旧进程送完旧客才退 |
| 惊群 | thundering herd | 一窝蜂醒来抢同一个新连接，多数白忙一场（现代内核已解决） |
| 反向代理 | reverse proxy | 站在真实服务器前面的前台接待员，客人只见前台 |
| upstream | — | 后台真正干活的服务器名单 |
| 负载均衡 | load balancing | 把活分给名单上几台服务器的分配规则 |
| 轮询 | round robin | 按名单顺序一家一个轮着来 |
| 故障转移 | failover | 一台坏了自动记下来、换下一台重试，别让客人看见失败 |
| 漏桶算法 | leaky bucket | 水先倒进固定漏斗、按固定速率漏出去；倒太猛直接溢出拒绝 |
| 突发余额 | burst | 漏斗上方临时加高的一段缓冲空间，偶尔倒猛点也不至于马上溢 |
| 缓冲 | buffer | 两个速度不一致的人之间摆的一张桌子，快的那方先把东西堆桌上 |
| 聚合写 | writev | 把几堆东西抱一次送出去，省得跑三趟 |
| 零拷贝 | zero copy | 货不进你家门：数据不搬到应用手里，从库房直接装车发走 |
| sendfile | — | 零拷贝在 Linux 上的官方通道——文件直接从磁盘送进网卡 |
| 慢速攻击 | Slowloris | 每条连接隔几秒发一个字节，拖住「攒完整包」服务器的内存 |
| 令牌桶 | token bucket | 漏桶的镜像：攒了令牌就能瞬时放行一批——限平均、允许攒突发 |
