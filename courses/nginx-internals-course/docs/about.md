# 关于本课程

这是一门给「nginx 的熟练用户」写的实现原理课。你对 nginx 的全部使用经验——写过的 `server` 块、抄过的 `proxy_pass` 和 `limit_req`、执行过的 `nginx -s reload`——在这里都会被拆开问到机制层：它凭什么又快又稳？reload 的一瞬间在线下载断没断？三台后端坏一台用户为什么看不见？

课程不读任何 C 源码。做法是用 TypeScript 亲手造一个最小的事件驱动 HTTP 服务器 **tinysrv**（约千行规模），让每一条原理都跑在你自己写的、可断言验证的代码上：连接注册表、HTTP/1.1 解析状态机、keep-alive、请求内存池、配置继承、反向代理、负载均衡与故障转移、漏桶限流——正文里的每段示例代码都出自这个随课程逐章长出来的实验场。

- **章节**：11 章全部完成（3 个分部：并发根基、工程支柱、流量主场），另有 4 个附录（术语表、信号速查、指令对照、练习路线）。
- **输入**：主题句「nginx 实现原理」，无源仓库依赖。
- **读者画像**：配过 nginx 且大致理解配置、懂 HTTP 概念（Method/Header/Body）、写业务级 TypeScript，但没接触过 socket 层编程——socket、信号、内核缓冲这些概念在书里全部从零教。
- **实验场**：`companion/`（TypeScript + vitest），每章先写断言原理行为的测试再实现，52 个测试全绿收官，含 127.0.0.1 真实 socket 的双跳代理与故障转移集成验证。

想动手跑实验场：`cd companion && npm install && npm test`。想从零把 tinysrv 再写一遍，见附录「练习路线」。
