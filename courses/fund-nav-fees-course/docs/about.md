# 关于本课程

这是一门面向普通投资者的计算课：基金净值怎么来、申赎按哪天净值结算、每一类费用怎么算。十章内容全部围绕「算得清」展开——每个承重数字都由课程伴带的核对脚本复现，你可以在课程仓库的 companion 目录用 `node src/check-answers.mjs` 逐条验证。

- 章节数：10 章（全部完成）
- 输入：主题句「基金净值与费率：申购赎回怎么算、费用藏在哪」（topic，无仓库输入）
- 课程形态：非编程知识课（演算核对 + 实操任务验证），正文代码默认折叠，面向非程序员读者
- 读者校准：本次生成按大纲受众保守默认画像运行，未经用户问卷校准——按课程生成规范如实注明

**内容时效**：文中费率区间与监管规则截至 2026-08 整理。基金费率、赎回费阶梯、惩罚性费率与披露口径可能随法规与基金合同调整，具体以各基金《基金合同》《招募说明书》及监管最新规定为准。

**合规声明**：本课程内容仅用于学习与计算方法演示，不构成投资建议，也不推荐任何具体基金或份额类别。风险与收益的判断不在本课程计算范围之内。
