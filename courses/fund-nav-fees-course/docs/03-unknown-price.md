# 未知价法：今天下午买，按哪天的净值算

前两章你算清了净值本身。现在看一个每天都会遇到、却几乎没人核对过的问题：你上午十点下单申购，晚上去查「确认净值」，那个数不是你下单那一刻屏幕上显示的净值。先别急着骂平台——规则本来就是这么写的，而且写成这样有充分的理由。

## 下单时，成交价还不存在

开放式基金的申赎采用未知价法（forward pricing）：申购和赎回都按「提交当日」收盘后计算出来的单位净值成交。也就是说，你下单时，这笔交易的成交价还没被算出来——你买的是「今天晚上才算出来」的那个数。

为什么不按你下单时看到的昨日净值成交？做个反事实推演就明白。假设按已知的 T-1 日净值成交：某天午后市场大涨 3%，所有知道消息的人都会抢在收盘前按昨天的低价申购，当天的高涨幅全部落进他们的口袋——这些钱从哪来？从存量持有人身上来。反过来说，大跌时赎回的人按昨日高价跑掉，亏损留给留下的人。未知价法切断了这条抢跑通道：**大家按同一个未知的当日价成交**，谁也没法占谁的便宜。这条规则保护的是继续持有的人。

## T 日：你的单子算哪一天

这里的「提交当日」有个专有名词：T 日（trade date），指一笔申赎被受理的交易日。判定规则一句话：**交易日 15:00 前提交，T 日就是当天；15:00 之后、或非交易日提交，顺延到下一个交易日**。结算净值用 T 日收盘后计算的净值。

把规则套进几个时间点（下面以无节假日的一周为例）：

```text
周四 14:30 申购 → T 日 = 周四，按周四净值
周四 15:30 申购 → T 日 = 周五，按周五净值
周五 15:30 申购 → T 日 = 下周一，按下周一净值
周五 14:00 赎回 → T 日 = 周五，按周五净值
```

跨时区品种（如 QDII——把钱投向海外市场的基金）的 T 日净值还叠加海外市场日历，确认更慢，但判定逻辑相同。各平台对截止时间的执行细节以销售机构说明与招募说明书为准（截至 2026-08）。

## 实操：在你的 App 里核对这套规则

- [ ] 打开任一基金销售平台的基金详情页，应看到「单位净值」旁标注着净值日期——它应是最近一个已收盘的交易日，而不是当天。
- [ ] 打开一笔自己的历史申购或赎回记录，应看到「确认日期」与「确认净值」（或「成交净值」）两个字段；核对确认日期与你下单时间的关系：15:00 前下的单，确认日期应是下单当日；15:00 后下的单，应是下一交易日。
- [ ] 在该平台的「交易规则」或「费率说明」页，应看到关于 15:00（下午 3 点）交易截止时间的明文说明，以及「按 T 日净值成交」的表述；应能找到两类顺延表述：交易日 15:00 后提交顺延至下一交易日、非交易日提交顺延至下一交易日。
- [ ] 先猜后跑：周五 15:10 提交赎回，按哪一天的净值？先把答案写下来，再去交易规则页核对，应看到「15:00 后提交的申请顺延至下一交易日」一类表述——它正对应你这道题的边界——如果与你的猜测不一致，回到上一节的时间线表重推一遍。

## 验证：猜对之后

上面第四条就是本章的「先猜后跑」：多数人会猜「周五」，规则答案是「下周一」。错的那一步通常不是不懂顺延，而是没意识到 15:10 已经越过了截止线。今后每次下单前看一眼时间，你就知道自己买的是「今天晚上」还是「明天晚上」的价格。

本章没有演算题，验证物就是那张任务清单：四条全部「应看到」具体到可对照的页面字段。全部核完，你对未知价法的理解就不再停留在名词上。

## 小结与自查

未知价法让所有人按同一个当日未知价成交，保护存量持有人不被抢跑套利；T 日的判定只看两件事——是不是交易日、有没有过 15:00。费用怎么算，是[第 4 章](./04-purchase-fee)的主题：你会看到「手续费后到账份额」和直觉算法的差，而且能精确到分。

- 自查二：如果允许按 T-1 日已知净值成交，暴跌当天的赎回者占了谁的便宜？

按昨日高价赎回，等于把今天的下跌留给没跑的持有人——反事实推演见「下单时，成交价还不存在」一节。
