# 术语表

全书首教过的术语在此集中可查；正文首现处均附一句人话解释，这里是那句话的正式版。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 基金份额 | fund shares | 把基金总资产切成的等份凭证，你持有的份数乘净值就是你的市值 |
| 单位净值 | NAV per unit | 一份基金当天值多少钱，等于总资产减负债再除以总份额 |
| 累计净值 | cumulative NAV | 单位净值加上历史上每份累计分掉的红利，用来还原不分红情况下的净值轨迹 |
| 基金分红 | dividend | 基金把一部分收益按份额发给持有人，发完当日净值等额下调，账面总值不变 |
| 份额折算 | share split | 基金把持有人的份额按比例调整、净值反向调整的记账动作，总值不变，常见于净值归一 |
| 未知价法 | forward pricing | 申购赎回按提交当日收盘后算出的净值成交，下单时谁也不知道成交价 |
| T 日 | trade date | 一笔申赎被受理的交易日，15:00 前提交算当天，之后或非交易日顺延到下一交易日 |
| 外扣法 | external deduction | 申购费的算法：净申购金额等于申购金额除以一加费率，费用隐含在价内 |
| 赎回费 | redemption fee | 卖出基金时按金额和持有期阶梯收取的费用，2026 新规下全额计入基金财产 |
| 惩罚性赎回费 | punitive redemption fee | 持有不足 7 日赎回时收取的不低于 1.5% 的费用，全额归基金财产，意在抑制超短期申赎 |
| 管理费 | management fee | 付给基金管理人的报酬，按前一日净资产乘年费率除以当年天数逐日计提，藏在净值里 |
| 托管费 | custody fee | 付给托管银行的费用，计提方式与管理费相同，费率更低 |
| 销售服务费 | sales service fee | C 类份额按日计提的渠道服务费，替代申购费；持有满一年停收（货基除外，2027-01 起执行） |
| 万份收益 | income per 10,000 units | 货币基金每持有一万份当天赚到的钱（元），是最直接的当日收益口径 |
| 七日年化 | 7-day annualized yield | 把最近七天万份收益平均后折算成的年化收益率，是折算口径不是承诺 |
| A 类/C 类份额 | share classes | 同一支基金按收费方式分的两类：A 类收一次性申购费，C 类免申购费但按日计提销售服务费 |
