# 申赎对账单：从买入到卖出一笔记到底

三章费用知识在手，现在做毕业题。有人赎回到账 22679.07 元，自己按「无费用」直算是 22770.01 元，差了 90.94 块。他去翻对账单，每一行都能看懂，却对不上总账。因为差价从来不会写成一行「合计少给你 90.94 元」，它藏在三个不同的地方。这一章把整条链路从头算到尾，让 90.94 元的每一分都有名有姓。

## 一张对账单，八个数字

场景：2 万元申购某股票型基金，申购费率一折后 0.15%，成交净值 1.0231；持有 220 天后赎回，赎回日净值 1.1648，按第 5 章示例阶梯落 0.25% 档。逐行计算，每行只用到前面某一章的一个式子：

```text
① 净申购金额 = 20000 ÷ (1 + 0.0015)          = 19970.04 元   ← 第 4 章外扣法
② 申购费用   = 20000 − 19970.04               = 29.96 元      ← 第 4 章
③ 申购份额   = 19970.04 ÷ 1.0231              = 19519.15 份   ← 第 4 章
④ 赎回金额   = 19519.15 × 1.1648              = 22735.91 元   ← 第 5 章
⑤ 赎回费用   = 22735.91 × 0.0025              = 56.84 元      ← 第 5 章阶梯（220 天落 0.25% 档）
⑥ 净到账     = 22735.91 − 56.84               = 22679.07 元   ← 第 5 章
⑦ 净收益     = 22679.07 − 20000               = 2679.07 元
⑧ 收益率     = 2679.07 ÷ 20000                = 13.40%
```

把这张表抄在纸上，跟着每一行重算一遍——这就是本课的终点能力：**给你任何一笔真实的申赎，你能在平台之外独立复现它的每一个数字**。第 6 章的管理费没有出现在表里。它不发生在你与基金的结算层，而是每天溶在净值 1.1648 的形成过程里——对账单看不见它，但 220 天的计提拖累实实在在压在这个净值中。

## 90.94 元的解剖

现在回答开头的问题：无费直算是 20000 ÷ 1.0231 × 1.1648 = 22770.01 元，与净到账差 90.94 元。两笔显性费用合计只有 29.96 + 56.84 = 86.80 元——还有 4.14 元去哪了？

拆开看。赎回费一分不少地贡献了 56.84 元。申购费的贡献却不止 29.96 元：它让你少买了 29.28 份（20000 ÷ 1.0231 与 19519.15 的差），这些份额始终没被买入。到赎回日，这些缺口共让你少掉约 34.10 元：其中 29.96 元是你交掉的费，4.14 元是这笔钱错过的上涨。34.10 + 56.84 = 90.94 元，账平——连那 4.14 元的残差也有了名姓。**申购费的真实代价是它造成的份额缺口乘以后续涨幅**——涨幅越大，入口费越贵。这个结论值得记住：长期持有的品种里，一次性费用的隐含成本会随时间放大。反过来读它也成立：如果你预计持有期很短、涨幅有限，入口费的隐含代价就小——这正是第 7 章 C 类份额在短持有期占优的数学原因，两章在这里会合成同一个结论。

## 验证：对上你自己的对账单

- 先猜后跑：看到「两笔费用合计 86.80 元、总差 90.94 元」时，先猜这 4.14 元的缺口来自哪里，再读上一节核对——多数人第一次都猜不到「费用的机会代价」这一层。（各行独立四舍五入的尾差处理见[差异清单](./divergence-list)。）
- 打开你自己的一笔完整申赎记录，按①至⑧的顺序逐行复算；确认单上的「确认份额」「手续费」「到账金额」应与你的第③⑤⑥行一致（尾差在分位以内）。
- 伴生仓核对：`node src/check-answers.mjs` 的 ch09 一节 8 条全绿——上表八个数字与脚本输出逐项一致；把 amount、navIn、navOut 换成你自己的真实数据重跑，得到你自己那笔账的复核结果。

## 把表读进你的确认单

平台的对账单字段与上表是一一对应的，只是叫法不同：「确认金额」对应①或③（看平台口径，「确认净值」则一定是申购日的单位净值）、「申购费用」或「手续费」对应②、「赎回金额」对应④、「赎回费用」对应⑤、「到账金额」对应⑥。逐行对过去，任何一行对不上，先检查你代入的费率档与净值日期——按第 3 章的规则，净值日期由 T 日决定，代错一天，④⑤⑥三行全错。

另一个常见陷阱是确认周期：普通基金赎回款几个交易日内到账，QDII 品种因跨市场结算要更久。到账慢不等于被扣费——判断依据永远是第⑥行的算式，而不是到账速度的体感。

## 小结与自查

八行对账单把四章的费用知识串成一条链：外扣法定入口、阶梯表定出口、日计提隐在净值里。差价从来不是一行，而是「显性费用 + 份额缺口 × 涨幅」的组合。能独立复现这张表，你就再也不需要「相信」平台的数字——你只能核对它。
