# 基金净值与费率：从看得懂的数字到算得清的账

一门面向非程序员读者的基金计算课：净值怎么来、按哪天结算、每类费用怎么算。全部承重数字由伴生核对脚本复现。

## 怎么跑

两条路：

- 项目根 `pnpm dev`，从聚合站进入本课程；
- 或在本目录 `pnpm install && pnpm docs:dev` 单独预览。

验证物工程（演算题答案核对 + 正文承重数字守门）：

```bash
cd companion && npm install && npm test        # 95 条核对全绿
node src/export-docs.mjs                        # 再导出正文承重数字（.course/verified-numbers.json）
```
