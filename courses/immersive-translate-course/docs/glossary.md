# 术语表

全书 29 个概念，每个一句话。按首教章的大致顺序排列；点击任一术语可回到 sidebar 找到对应章节。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 双语对照 | bilingual display | 原文不动、译文紧跟其下逐段显示的翻译呈现方式。 |
| DOM 树 | DOM tree | 浏览器把 HTML 解析成的活对象树，页面上每个标签是树上一个节点。 |
| 块级元素 | block-level element | 默认独占一行显示的元素（段落、标题、列表项），页面的段落感由它们组成。 |
| 内联元素 | inline element | 默认待在行内不换行的元素（加粗、链接、行内代码）。 |
| 可译块 | translatable block | 直接持有文字的最小块级元素，双语引擎抽取、翻译、插入的基本单位。 |
| 直接文本 | direct text | 一个节点自己名下的文本，不含更深层子块里的文本。 |
| 跳过规则 | skip rules | 判定某节点不该翻译的规则清单（代码块、脚本、纯符号、过短文本）。 |
| 树遍历 | tree traversal | 从根递归走完整棵树、给每个节点分类的算法——文件系统递归遍历的 DOM 版。 |
| 兄弟节点插入 | sibling insertion | 把新节点插到某节点的旁边（同级）而非它里面，原文子树零接触。 |
| 依赖注入 | dependency injection | 把「翻译服务」从引擎内部抽出来当参数传进去，引擎只认接口不认具体服务。 |
| 假翻译器 | fake translator | 确定性的假翻译函数：输入固定输出就固定，让全链路离线可测。 |
| 内联切分 | inline splitting | 按内联边界把一个段落拆成片段分别翻译，再按原结构拼回。 |
| 占位标记 | placeholder | 用翻译过程不会破坏的记号暂代内联标签，译文回来后替换回真实节点。 |
| 链接密度 | link density | 一块文字里链接字符占总字符的比例，高到离谱多半是导航或目录。 |
| 文字密度 | text mass | 一个区域里可译字符的总量，主内容识别里当区域的「分量」用。 |
| 启发式 | heuristic | 用经验规则猜答案的方法：快、够用，但不保证全对。 |
| 并发上限 | concurrency limit | 同时最多允许几个请求在飞的容量闸门，超出的排队等待。 |
| 批量接口 | batch API | 一次调用收发一批文本的接口形态，条数与顺序一一对应，摊薄每次往返的固定开销。 |
| 去重 | dedup | 同一轮送翻前把相同文本合并成一句，重复段落只付一次钱。 |
| 内容寻址缓存 | content-addressed cache | 用内容的哈希当键的缓存，同样的段落永远命中同一条。 |
| 管线组装 | pipeline assembly | 把抽取、翻译、渲染三道工序接成一条流水线，一次调用跑完全程并返回成绩单。 |
| 幂等 | idempotent | 同一操作做一次和做多次结果相同，重复渲染不产生重复译文。 |
| MutationObserver | — | 浏览器提供的「DOM 变了就通知我」的监听接口。 |
| 增量抽取 | incremental extraction | 只抽「新上树的子树」里的可译块、老块不重翻的增量口径——观察者对「新」的定义。 |
| 自触发循环 | self-triggering loop | 自己插入的节点又触发自己的监听器，译文生译文直至页面卡死。 |
| 标记属性 | marker attribute | 插入译文节点时打上的 data-* 属性，引擎靠它认出自己的产出。 |
| 重排 | reflow | 浏览器因 DOM 变化重新计算页面布局的过程，大规模重排是卡顿来源。 |
| content script | — | 浏览器扩展注入到网页里运行的脚本，引擎在真浏览器里的落脚点。 |
| manifest | — | 扩展的身份证兼配置清单，浏览器靠它认识你的扩展。 |
