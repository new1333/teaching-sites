# 让模型看图把关：视觉精排

粗筛的尺子免费转了一周，你拿它问了个新问题：「退货政策怎么规定的」。`score_pages` 给出的前四名，全是用「退货」二字最勤的页——附录那页把「退货」抄了二十遍，稳居第一。你把这四页翻了个遍，没有一页讲政策。真正的答案在第 61 页，标题是「售后与退换」。

退货和退换，说的是一回事，字面是两回事。第 5 章那把尺的全部输入是「字的重合」：问题切出的词，要在页面里逐字找到才算命中。第 61 页切不出「退货」两个字，得分是零——它不是排得靠后，是根本排不进来。你试过笨办法：96 页逐页发视觉大模型问「这页讲退货吗」，答案确实准了，账单也来了——光筛选就 96 次调用，比回答本身还贵，而且这笔钱每次提问都要重付一遍。

这一章给漏斗装第二层：粗筛免费圈出候选，把候选页的图和摘要一次性摆到模型面前，让它按内容挑出最相关的几页。一次调用，替掉九十六次。它补的正是字面检索的天生盲区。

## 词面对不上，尺子再准也量不出

先把盲区说精确。第 5 章的粗筛做的是词面匹配——只比较字面的检索方式：问题切成词，页面摊成文档，两边按「字面是否相同」对暗号。TF-IDF 改变的只是命中词的权重，不改变命中规则：词对不上，权重再高也是零。锚点收一句：对暗号只对字面——问「退货」，就永远对不上只写「退换」的那页。

拿真实词表手算一遍。「退货政策怎么规定的」是连续中文串，滑窗切出 {退货, 货政, 政策, 策怎, 么规, 规定, 定的}，「怎么」是停用词先扔掉。第 61 页写「售后与退换：七日内可办理」，切出 {售后, 后与, 与退, 退换} 加 {七日, 日内, 内可, 可办, 办理}——冒号断开中文串，两段各自滑窗。两个集合没有交集：得分 0，这页不进榜。全书「退货」字样出现得越多，越把它压到看不见的位置。

为什么共享一个「退」字也救不了？滑窗切出的是双字词，「退货」与「退换」第二个字不同，整词就不同。中文里这样的同义对是长尾：退货与退换、返修与维修、逾期与超期、报销与核销。手工维护同义词表？每换一个领域就要重编一张，枚举不完，也维护不动。

字面是死的，语义是活的。「这两句说的是不是同一件事」，恰好是大模型每天都在做的事。让模型补这个盲区，不是请它重新检索全书——只让它看粗筛圈出的那一小撮候选。分工不变：免费的粗筛管圈，便宜的模型管挑。成本漏斗的第二层，就立在这道分工上。

盲区不用信我，两行代码可以亲自量出来：

```python
# 用法示例：亲眼看一次盲区（companion 目录下，先设 PYTHONPATH=src）
from vision_rag.scoring import tokenize

q = tokenize("退货政策怎么规定的")
page = tokenize("售后与退换：七日内可办理")
print(sorted(q & page))   # [] —— 词面零交集，这页粗筛永远检不到
```

## 一次摆开挑前几名：top-k

候选圈出来，怎么让模型挑？最直觉的还是逐页问——12 个候选问 12 次。更好的做法是一次调用：12 页的图和摘要标签放进同一个请求，末尾附上问题，让模型挑出最相关的几页。这就是 top-k（top 指前几名，k 指要的个数）——只取挑选结果里排最前面的 k 名，比如 k=4 就只要 4 页。

一次摆开除了省钱，还买到了「比较」。精选本质是比较题：第 61 页值不值得选，要跟同场的第 3 页、第 45 页比过才知道。逐页问是让模型对每页独立表态，没有参照物，答「相关」的尺度会漂。摆开问，模型看的是一整排候选人。招聘漏斗里这一层叫面试精选：机筛免费圈人，面试官一场看一批，挑出进终面的少数；终面最贵，只留给最后几页。

账可以纸笔复算，口径沿用第 1、3 章声明的简化模型：

```text
问一次 96 页手册，「筛」这一步的三本账

  方案 A  无粗筛，逐页问模型              96 次调用
  方案 B  粗筛圈 12 候选，逐页问          12 次调用（圈候选免费）
  方案 C  粗筛圈 12 候选，一次摆开挑       1 次调用

  页图门票：一页 110 DPI 页图约 2 token（第 3 章口径）
  方案 C 一次带 12 页图约 24 token，加 12 条摘要标签，仍是零头
```

96 到 12，免费层先砍掉八分之七；12 到 k，便宜层再一次收窄。这正是第 1 章「每问代价压到约八分之一」的兑现处。

给模型看什么，每页「标签在前、图随后」。标签是 `[第N页]` 加标题与摘要——摘要是第 4 章模型浅阅读的浓缩，帮它快速定位；图是内容判断的根据——版式、表格、盖章，这些字面上不存在的信息只有图里有。扫描页文字层是空的，只发文字它就是隐形的，发图它才存在。这次调用用 `effort="low"`（最低推理档）：候选最多十来页，每页看一眼「讲不讲这件事」就够，贵的档位留给下一层的深读。

## 模型说「第 99 页」：输出不可信，校验三闸

第 1 章立过原则：模型的回复是生成出来的，不是查询出来的。格式层的毛病（围栏、尾逗号）`parse_json_lenient` 已经在救；语义层的毛病这层管——回执说选中第 99 页，可请求里根本没有第 99 页。

页码的合法性不来自模型，来自送审名单。这是第 3 章「页码与图像一次绑定」的纪律在精排的延续：模型只准在摆到它面前的页里挑。于是回执要过三道闸：

- 只认候选：不在候选内的页码，编得多自信都丢弃；
- 去重：模型热情起来会把同一页推荐两遍，只留一次；
- 不超过 k：合同写明最多 k 页，多给的截掉。

三道闸全灭、一个合法页码都没剩怎么办？走下一步的退路——精排没有一票否决权。

## 贵的一层倒了，便宜的一层还在：回退

精排是漏斗里第一次花钱的判断，于是第一次直面这个问题：调用失败了怎么办？网络抖动、限流、引擎罢工——第 2 章的 Client 会按指数退避重试四次，四次烧完抛 ChatError。这一层的回答是回退（fallback，字面是「退回去」）——高档手段失败时，退回低档手段继续干活的策略：精排倒了，退回粗筛的排序，取前 k 名。

三个触发条件走同一条退路：调用层罢工（ChatError）、模型一页未选（回空列表）、校验三闸全灭。共同点是精排交不出判断。而这正是第 5 章处理过的同一种失败：粗筛没主意时交回全部页序，精排没主意时交回粗筛的排序。每层的失败模式都是降级，不是崩。你问手册一个问题，不该因为精排这一跳网络不好就整体失败——答案质量降一档，提问不断线。

还有一笔第 5 章留下的账在这层兑现：粗筛故意不过滤空白页，把关的活留给精排。兑现方式很直接——空白页在入口就拦下，不送审，也不进结果。图上无墨的页没什么可挑；它的页码哪怕混进候选，也只是白占一个送审名额。

## 实验场：pipeline.py

新文件 `src/vision_rag/pipeline.py`：漏斗后两层（精排、深读）与将来的贯通入口都住这里，本章先落第二层。先看写给模型的岗位说明书：

```python
# src/vision_rag/pipeline.py · RERANK_SYSTEM
RERANK_SYSTEM = """你是页面精选员。你会收到一批候选页：每页前有一条标签（页码、标题、摘要），标签后是这页的图片。
用户会提出一个问题，请挑出真正有助于回答它的页面，最多 {k} 页，按相关程度从高到低排列。
判断看内容与语义，不要只对字面——写「售后与退换」的页，同样可能回答「退货」的问题。
宁可少选，不要凑数；一个都不相关就返回空列表。
输出 JSON：{{"pages": [{{"page": 6, "reason": "10字以内理由"}}]}}，只输出 JSON。"""
```

模板里的 `{k}` 由 `format` 填入，JSON 的花括号双写转义。两句指令各有用意：「判断看内容与语义」直接点名字面盲区；「一个都不相关就返回空列表」给模型拒判的出口——空列表随后有退路接住。

每页的送审标签由一个小函数拼出，页码打头：

```python
# src/vision_rag/pipeline.py · _cand_label
def _cand_label(page: int, card: PageCard) -> str:
    """候选页的送审标签：页码打头，标题与摘要随后——页码引用的物理出处。"""
    label = f"[第{page}页]"
    if card.headings:
        label += " 标题：" + "；".join(h["text"] for h in card.headings)
    if card.summary:
        label += f" 摘要：{card.summary}"
    return label
```

主函数全貌（后续章的深读与贯通入口将增补进同一文件）：

```python
# src/vision_rag/pipeline.py · rerank_pages
def rerank_pages(client, cards: dict[int, PageCard], page_images: list,
                 candidates: list[int], k: int,
                 question: str) -> list[int]:
    """视觉精排：候选页图＋摘要交模型，按内容选出至多 k 页，返回页码列表。

    回执按「不可信输入」对待：只接受候选内的页码、去重、截到 k 条。
    空白页、没有卡片或页图的候选在入口即被拦下——进不了图，就参与
    不了「看图把关」。调用层罢工或模型一页未选时，静默回退粗筛排序
    的前 k：精排的失败模式是「没判断」，不是「崩」。
    """
    if k <= 0:
        raise ValueError(f"k 必须是正数，收到 {k}")
    images = {img.page_no: img for img in page_images}
    cand = [p for p in candidates
            if cards.get(p) is not None
            and cards[p].type != "空白"                     # 空白页这层把关
            and p in images]                                # 无图：进不了送审
    if not cand:
        return []
    blocks: list[dict] = []
    for p in cand:
        blocks += img_block(images[p].bitmap, _cand_label(p, cards[p]))
    blocks.append({"type": "text",
                   "text": f"用户问题：{question}\n"
                           f"请从上述 {len(cand)} 个候选页中选出最多 {k} 页，"
                           "按相关程度从高到低输出。"})
    try:
        data = client.chat_json(blocks, system=RERANK_SYSTEM.format(k=k),
                                effort="low")
    except ChatError:
        return cand[:k]                          # 罢工：静默退回粗筛排序
    picked: list[int] = []
    raw = data.get("pages") if isinstance(data, dict) else None
    for item in raw or []:
        try:
            p = int(item["page"])
        except (KeyError, TypeError, ValueError):
            continue                             # 形状不对、页码不是数：扔
        if p in cand and p not in picked:
            picked.append(p)                     # 只认候选、去重
    return picked[:k] or cand[:k]                # 一页未选：同样还给粗筛
```

走读一遍。入口先做参数纪律与「进得了场」的过滤：空白页、没有卡片或页图的候选拦在门外。随后逐页拼标签加图，问题收尾，`chat_json` 一次发出。回执循环里三道闸原样落地：`int(item["page"])` 转不动的扔，`p in cand` 只认候选，`p not in picked` 去重，`picked[:k]` 截到合同上限。两处 `cand[:k]` 就是退路的两个入口：`except ChatError` 接住重试耗尽，`picked[:k] or cand[:k]` 接住空选与全灭。全程静默——不打印，不抛出，调用方只看到结果，看不到过程的失败。

## 验证：跑什么，看到什么

本章里程碑全部写成测试，钉在 `tests/test_vision_rerank.py`，11 个测试分四组，各验一事：

- **语义命中**——8 个候选、问题「退货政策怎么规定的」，剧本回放挑中第 3 页（摘要「售后与退换」）与第 7 页（「退换货办理流程」），两页都不含「退货」字样；另断言请求形状：8 张图、8 条标签、问题收尾、低推理档、JSON 模式；
- **回执校验**——回执混入编造页码 99、不在候选内的页 9、重复的 3、非法值 None，结果只剩 [3, 5]；模型给 4 页而 k=2 时只留前 2，且按模型的相关度序；
- **回退**——剧本连续罢工四次烧完重试，返回值恰为本地排序前 k，全程不抛错（`transport.calls == 4` 把重试烧过的次数留了案底）；模型一页未选时同样退回本地前 k，不是空列表；
- **空白页把关**——空白候选根本不进送审名单（请求标签里查无此页），模型硬选也拿不回；没有页图的候选同样进不了场、回退时也不占名额；候选全是空白页时一次调用都不发。

参数纪律另有两小条：k 非正数抛 ValueError，候选为空返回空列表。

from vision_rag.bitmap import Bitmap
from vision_rag.client import ChatError, Client
from vision_rag.document import PageImage
from vision_rag.fake import ScriptedTransport, fenced_json
from vision_rag.index import normalize_card
from vision_rag.pipeline import rerank_pages

print(sorted(tokenize("退货政策怎么规定的")
             & tokenize("售后与退换：七日内可办理")))    # [] —— 词面零交集

cards = {p: normalize_card({"type": "正文", "summary": "常规说明"}, p)
         for p in range(1, 9)}
cards[3] = normalize_card({"type": "正文",
                           "summary": "售后与退换：七日内可办理"}, 3)
images = [PageImage(p, Bitmap(["页图"] * 3)) for p in range(1, 9)]
pick = [(fenced_json({"pages": [{"page": 3, "reason": "售后退换"}]}), "stop")]
print(rerank_pages(Client(ScriptedTransport(pick), sleep=lambda _s: None),
                   cards, images, list(range(1, 9)), 2,
                   "退货政策怎么规定的"))                    # [3] —— 看图补上盲区

strike = ScriptedTransport([ChatError("boom")] * 4)
print(rerank_pages(Client(strike, sleep=lambda _s: None),
                   cards, images, [5, 3, 8, 1], 2,
                   "退货政策怎么规定的"))                    # [5, 3] —— 罢工退回本地前 k

三个打印就是三段证词。第一个空列表：字面上，那页与问题零交集。第二个 [3]：同样的问题、同样的页，摆到看得见图的模型面前，选中了。第三个 [5, 3]：引擎全程罢工，函数照样返回粗筛排序的前两名。盲区补没补上、退路通不通，输出就是全部证据。

## 收线：从「对上字」到「看懂页」

回头看「筛」这件事的台阶。第 5 章之前，要么字面瞎排（长页霸榜），要么全问模型（96 次调用）。第 5 章用 TF-IDF 把「字面对得上」的页免费排了序。这一章补上第二只眼：字面对不上但内容相关的页，让看得见图的模型在一次调用里挑回来。粗筛管字面，精排管内容；粗筛免费，精排一次调用。两层合起来，候选从 96 页收到 k 页，且每层失败时都有下一档兜着——检索增强生成「先翻书」的半边，翻到这里又快又准。剩下的最后一层，是把选中的页真正读透。

```text
本章落成的东西，后面谁在用

  rerank_pages      漏斗第二层：候选页图＋摘要一次摆开，模型挑 top-k
  回执校验三闸      只认候选、去重、不超过 k——页码合法性来自送审名单
  回退纪律          罢工 / 空选 / 全灭，都静默退回粗筛排序的前 k
  空白页把关        第 5 章留下的账在此兑现：不送审，不进结果
  pipeline.py       深读与全流程贯通入口的宿主文件（后续章续写）
```

同一套「候选摆开、模型挑选、校验、回退」，第 11 章会原样搬进视频的段精排。那之前，下一章先给选中的页配上邻页、页图与文字层，用最高的推理档读透它们——漏斗最后一层，也是最贵的一层。

离开前自查四问：

- 「退货政策怎么规定的」切出的词，哪几个出现在写「售后与退换」的页上？答案为什么是零个？
- 精排为什么把 12 页摆进一次调用，而不是逐页问？除了省钱，「同场比较」还解决了什么问题？
- 模型回执给了第 99 页，校验凭什么丢弃它？页码的合法性来自哪里？
- 剧本罢工四次烧完重试后，`rerank_pages` 返回什么？这和第 5 章「无词命中回退全部页序」有什么共同点？
