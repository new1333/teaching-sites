# 课程介绍

这是一门讲**视觉 RAG 原理**的课：让 AI 真正「看懂」PDF 与视频，并给出带页码、时间戳引用、可核对证据的回答——它背后的两阶段架构与三层成本漏斗是怎么成立的。

课程全部 14 章已完成：第一部立全景与地基，第二部沿 PDF 问答主线把渲染、索引、粗筛、精排、深读、可核对交付逐层造出来，第三部把同一套漏斗迁移到视频（抽帧、段聚合、时间戳问答、微观放大），第四部收在引擎移植与把脚本打包成 agent skill。

本课程的备课参考了一个公开的视觉 RAG 工具仓库（作者侧学习资料）：[liangdabiao/glm-5.3-flash-vision-rag](https://github.com/liangdabiao/glm-5.3-flash-vision-rag)。课程不复刻它的代码：正文与实验场零仓库痕迹，所有示例出自课程自建的伴生实验场——一套由「假模型」驱动的最小视觉 RAG 管线，全部测试本地零网络跑通。

读者画像：会写基础 Python 脚本（函数、字典、文件读写），没调过大模型 API、没做过 RAG 也能读——专业名词第一次出现时都会当场用一句人话解释。
