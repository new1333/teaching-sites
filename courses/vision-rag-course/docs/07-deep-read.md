# 只在刀刃上花力气：深读与引用诚实

漏斗的前两层终于可信了：粗筛免费圈出候选，精排一次调用挑出最相关的几页。你拿它问「全年耗材成本的趋势如何」，精排选中第 40 页——那页画着耗材成本表。答案很快回来：全年逐季下降，证据确凿，页码还标着 `[第40页]`。你在周会上照着汇报，财务当场翻出原件：这张表在第 40 页只印得下上半段，第一到第三季度；第四季度的两行和趋势结论，排在第 41 页。全年明明是逐季上升。模型没撒谎，它只是只看过半张表——半张表推全年趋势，只能猜，而且猜反了。你照着一个猜反的答案做了汇报。

回头再试一个更扎手的。问一个手册里根本没有的问题：「预算表在哪一页」。这次模型一本正经编了个 `[第53页]` 的引用，你翻过去——空白页。上一章的精排把「编造候选外的页码」拦得干干净净，可那管的是挑选层；到了回答层，模型自己写下的答案里再冒出一个页码，还没有人核对。

这两件事，一个是「证据不全」，一个是「证据没有」，病根不同，药也不同。这一章给漏斗装最后一层——深读，让视觉大模型把选中的几页真正读透：命中页要带上前后一页，别让证据断在页缝上；每页的图与文字层一起给，两条通道各管各的；给模型一个说「资料里没有」的合法出口，宁可不答，不许现编；推理档位拧到最高，好钢用在刀刃上。漏斗收到这里只剩几页——全书最贵的那次调用，正好全花在这几页上。

## 断在页缝上的表格：带上邻页

先医第一个病根。排版为内容服务，不为你的问题服务：一张表印到哪里，页缝就断到哪里。第 40 页放不下的行，自然流到第 41 页；论证写了一半，结论翻页再续。精排选出的是「最相关的那页」，可最相关的那页未必自成整体——它可能只是半张表。

所以深读的第一件事，是把命中页的前后一页一起带上。这就是邻页（neighbor page）——命中页的前一页和后一页，也就是页码加减一范围内的那几页。锚点收一句：表格上半段在这页、结论在下一页，只看一半必猜错；带上邻页，模型看到的才是完整的证据。

```text
页码轴   ··· 38  39  40  41  42  43 ···
                      ┌─────┐
精排选中               │ 40  │                命中 1 页
                      └─────┘
               ┌─────┬─────┬─────┐
深读送读        │ 39  │ 40  │ 41  │           展开 3 页：前一页、命中页、后一页
               └─────┴─────┴─────┘

两条边界纪律：
· 第 1 页只带出 {1, 2}，末页（第 N 页）只带出 {N-1, N}——没有第 0 页
· 空白页不进名单——图上无墨，读不出东西，白占上下文
```

这笔账可以纸笔复算。设精排选了 k=4 页，命中 {8, 40, 41, 90}：

- 8 展开 {7, 8, 9}；40 展开 {39, 40, 41}；41 展开 {40, 41, 42}；90 展开 {89, 90, 91}；
- 并集去重，得 {7, 8, 9, 39, 40, 41, 42, 89, 90, 91}，共 10 页；
- 上下界也随之推出：各命中页互不相邻时最多 3k=12 页；全部相连时共享邻页，最少 k+2=6 页。

按第 3 章声明的口径，一页 110 DPI 页图约 2 token，10 页图的门票约 20 token——比精排那一跳贵不了多少，买到的却是「不断在页缝上」的完整性。反面的两条路都走过：只给命中页，就是本章开头猜反的半张表；全书都给，就是第 1 章算过账的整本塞。邻页是折中，而且它是纯本地的集合运算——一次模型调用都不用。真实工程里这个半径常按页型可调——表格页多带一页、正文页少带；实验场把它固定成 ±1，少一个旋钮。

## 一份证据，两条通道：页图与文字层

深读的第二个决定：每个送读的页，图和文字层一起给。第 3 章渲染页图时零成本抽出的文字层，在这里派上正经用场。两条通道分工明确：

- 页图管「长什么样」：表格的行列结构、图表的形状与趋势、盖章与签名、版式与位置。扫描页的文字层是空的，图是它唯一的通道；
- 文字层管「写的是什么」：精确措辞、数字、型号、单位、人名。模型从图里认字靠看形，长串数字可能错一位、形近的字可能看串行；文字层是排版时的原文，一个字符不差。

答案要标页码时，两条通道指认同一批出处：标签贴在图前，文字层每行也用同一个页码打头。引用的物理出处只有一处，证据却有两份，互为校对。

扫描页在这份文本里如实标注「（无文字层）」——第 3 章 `is_scanned` 的判定，到这里变成对模型说的一句实话：这一页请读图。不冒充有字，也不悄悄跳过。成本侧同样是白赚：文字层与图进同一个请求，不增加调用次数。顺带声明一处简化：这里的文字层整页全文送入；真实的长页要配截断策略，只送与问题相关的段落。

## 「资料里没有」是一句合法的回答：拒答

第二个病根更隐蔽。手册里没有预算表，模型为什么编页码？第 1 章讲过幻觉的根：生成不是查询，模型的每个字都是「接着上文写下去」写出来的。你把问题递过去，它接到的任务就是回答——当「不答」不是一个选项时，「编一个像样的」比「说没有」更顺它的惯性。

所以要给模型一个合法的出口。这就是拒答（refusal）——证据不足时，明确说出「资料中未见相关内容、还缺什么」，而不是现编一段。锚点收一句：诚实的助手，资料里没有就说没有。

拒答要成立，两边都得配合：

- 岗位说明书里写明话术与条件：页面不足以回答时，说明缺什么，不要编造。出口写在说明书上，模型才知道往哪走；
- 管线这边**原样透传**。拒答文本回来，不重试、不包装、不追加客套——重试一次，等于告诉模型「这个答案不行，换一个」，多半会把「没有」洗成「编一个」。

诚实还管到页码。说明书要求：每个关键论点标注来源页码，**页码只能照抄请求里的标签**，不要编造。第 3 章「页码与图像一次绑定」的纪律，到这里交到答案层。万一模型还是编了呢？防线分两段：本章管「源头少编」；回收对账——把答案里的页码捞出来，与送读过的页核对——留给下一章的引用回收。账，总要对得上。

## 终面细聊：高档推理与给足预算

第 2 章装机时留过一个旋钮：推理强度。批量打标用 low——一页看一眼、归个类，不值得深思。这一章终于拧到 high。道理还是成本漏斗：招聘漏斗里终面细聊最贵，所以只在最后几个人身上花。深读是PDF 主线唯一一处 high——前面所有层的工作，都是为了把这次昂贵调用要读的页，收到最少、最准。

预算也要给足。方向性的事实是：这类引擎的思考过程计入输出预算，思考越长，留给正文的空间越少——预算紧的时候，答案会被自己的思考挤截断。所以深读的 `max_tokens` 开到 24576。声明一处简化：这个数值是本课程的教学选择，不是任何平台的真实口径；真实预算随引擎与版本变化，本书不写死数值。

截断了也不装完整。回复带着 `finish='length'` 回来时，文末追加一句「（注：回答因长度限制被截断）」。对照第 4 章很有意思：同样是截断，索引层的反应是对半拆批重试，因为拆批治「装不下」；深读层不拆——输入本来就只有几页，截断是「说不完」，治法只有如实说破。

## 实验场：pipeline.py 续写 deep_read

三个部件先后落在 `src/vision_rag/pipeline.py`：岗位说明书、邻页展开、主函数。先看写给模型的岗位说明书：

```python
# src/vision_rag/pipeline.py · DEEP_SYSTEM 与预算常量
DEEP_SYSTEM = """你是深度阅读助手。你会看到与用户问题相关的若干页面：每页先有一条页码标签（形如 [第6页]），标签后是页面图；请求末尾还有这些页的文字层。
阅读要求：
1. 图与文字层都要读，分工不同：表格、图表、版式、盖章以图为准；精确措辞、数字与名称以文字层为准；
2. 先给结论，再列要点；每个关键论点后标注来源页码，格式如 [第6页]——页码只能照抄你看到的标签，不要编造；
3. 若这些页面不足以回答问题，明确说明「资料中未见相关内容」、还缺什么，不要编造答案。
用中文作答。"""

DEEP_MAX_TOKENS = 24576   # 深读预算给足：高档推理下思考过程也占输出预算，饿着它答案会被自己的思考挤截断
TRUNCATION_NOTE = "\n\n（注：回答因长度限制被截断）"
```

三条要求各对一件事：第 1 条是两条通道的分工，第 2 条是引用诚实，第 3 条是拒答出口。截断注记单独存成常量——它拼在答案末尾，测试要认它。

邻页展开由一个小函数管完：

```python
# src/vision_rag/pipeline.py · _expand_pages
def _expand_pages(cards: dict[int, PageCard], page_images: list,
                  pages: list[int]) -> list[int]:
    """邻页展开：每个命中页带上前后各一页，去重后按页码升序返回。

    展开的边界不是「加减一算出来就行」：只收有页图、有卡片、非空白的
    页——空白的邻页读不出任何东西，白占上下文；语料外的页码（第 0 页、
    末页的后一页）自然落在范围外。返回的页序恒为升序，与命中页的输入
    顺序无关——后面的文字层块按这个顺序拼，页与页的先后不漂移。
    """
    readable = {img.page_no for img in page_images
                if cards.get(img.page_no) is not None
                and cards[img.page_no].type != "空白"}
    expanded: set[int] = set()
    for p in pages:
        expanded.update(q for q in (p - 1, p, p + 1) if q in readable)
    return sorted(expanded)
```

走读一遍。`readable` 先立边界——有页图、有卡片、非空白，三者齐备才算「读得了」；命中页逐个贡献前、中、后三个页码，撞上首尾边界的自然落空；`set` 去重，`sorted` 定序。签名里带着 `cards`，用意与上一章同源：空白页把关要查卡片。

主函数全貌（全流程贯通的入口在后续章节增补进同一文件）：

```python
# src/vision_rag/pipeline.py · deep_read
def deep_read(client, cards: dict[int, PageCard], texts: list,
              page_images: list, pages: list[int], question: str) -> str:
    """漏斗第三层深读：命中页 ±1 展开，页图与文字层同给，高档推理作答。

    页图管版式与图表，文字层管精确措辞——两条通道进同一个请求；回答里
    的页码引用出自请求里的 [第N页] 标签（第 3 章立的物理出处）。证据
    不足时模型按岗位说明书回「资料中未见相关内容」，本函数原样透传——
    拒答是被设计出来的诚实，不是要修的错。回复被截断（finish='length'）
    时文末追加注记，把「答案不完整」说出来，不默默交给用户猜。
    """
    if not pages:
        raise ValueError(f"pages 为空：深读需要至少一个命中页，收到 {pages!r}")
    if len(texts) != len(page_images):
        raise ValueError(
            f"texts 与 page_images 必须按位等长：{len(texts)} 对 {len(page_images)}")
    read = _expand_pages(cards, page_images, pages)
    if not read:
        raise ValueError(f"邻页展开后没有可读的页：命中 {pages!r} 既无图也无卡")
    images = {img.page_no: img for img in page_images}
    text_of = {img.page_no: t for img, t in zip(page_images, texts)}
    blocks: list[dict] = []
    for p in read:
        blocks += img_block(images[p].bitmap, images[p].label)  # 标签在前图随后
    layers = [f"[第{p}页] {text_of[p].strip() or '（无文字层）'}" for p in read]
    blocks.append({"type": "text",
                   "text": "重点页文字层：\n" + "\n".join(layers)
                           + f"\n\n用户问题：{question}"})
    text, finish = client.chat(blocks, system=DEEP_SYSTEM, effort="high",
                               max_tokens=DEEP_MAX_TOKENS)
    if finish == "length":
        text += TRUNCATION_NOTE                      # 截断要说破，不能装完整
    return text
```

走读三处。入口两道参数闸：命中页为空、texts 与 page_images 不按位等长（第 4 章立的对齐约定），都当场报错。中段拼请求：每页「标签在前图随后」——`images[p].label` 就是第 3 章那个 `[第N页]` 属性，引用出处直接复用；文字层逐页一行，空白的如实写「（无文字层）」，问题收尾。调用参数就是本章的三件主张：effort 拧到 high、预算给足、不开 JSON 模式——回答是给人读的散文，不是结构化数据。回文原样透传，唯一的加工是截断注记，且只在 `finish='length'` 时发生。

## 验证：跑什么，看到什么

本章里程碑全部写成测试，钉在 `tests/test_deep_read.py`，12 个测试分四组：

- **邻页展开**——命中 {40} 送读恰为 {39, 40, 41}；乱序、重复的输入照样去重且页码升序；第 1 页只带出 {1, 2}、末页只带出 {44, 45}；空白的邻页根本不进名单；
- **请求形状**——标签在前图随后，三页三图；末块文本含每页文字层与问题；扫描页如实标「（无文字层）」；
- **高档推理**——`reasoning_effort` 为 high、预算高于客户端默认档、不开 JSON 模式、岗位说明书在场；
- **诚实回答**——剧本回「资料中未见相关内容」时返回值与剧本一字不差；`finish='length'` 时正文保留、文末注记含「截断」。

参数纪律另有三小条：命中页为空抛 ValueError 且一次调用都不发；命中页在语料之外、展开后无页可读同样报错；texts 与 page_images 不等长报错。

## 收线：从「挑对页」到「读透页」

回头看「读」这件事的完成。第 4 章的批量打标是浅读——每页几十字摘要，为了检索；这一章是深读——选中的几页连同邻页，图与文字层同给，最高推理档，为了回答。检索增强生成的「翻书」半边到此三层齐备：免费的粗筛圈候选，便宜的精排挑页，昂贵的深读读透。每层只把下一层要用的东西收窄一点，钱都花在刀刃上。

```text
本章落成的东西，后面谁在用

  deep_read         漏斗第三层：±1 邻页展开、页图+文字层同给、effort=high
  邻页展开          命中页前后各带一页，去重升序；空白邻页不进场
  拒答透传          「资料中未见相关内容」原样返回，不重试不包装
  截断注记          finish='length' 时文末说破，不装完整
  DEEP_SYSTEM       引用诚实与拒答出口的岗位说明书
```

深读产出的是带 `[第N页]` 引用的回答，但它眼下还只是函数返回值，没到用户手上。下一章把它递出去：从答案里回收页码、导出引用页图、生成双击可开的单文件 HTML——回答必须可核对，编没编页码，对账见分晓。同一套「邻页展开、双通道、高档深读」，第 11 章会原样搬进视频的段深读。
