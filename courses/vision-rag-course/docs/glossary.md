# 术语表

全书首教过的术语，按首次出现的大致顺序整理成表。定义就是正文首现时那句人话。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 视觉大模型 | Vision Language Model / VLM | 能同时读文字和图片、就内容对话的大模型——一位看得见照片的远程助手。 |
| 多模态 | multimodal | 一个模型同时处理多种信息类型（文字加图片），而不是只会读纯文本。 |
| 上下文窗口 | context window | 模型一次调用里能摊开读的全部内容上限——助手桌面就这么大，塞满就放不下。 |
| 检索增强生成 | RAG | 先从资料里找出相关内容、再让模型照着找到的部分回答——开卷考试，不是闭卷背诵。 |
| 成本漏斗 |  | 三层筛选结构：免费的本地粗筛先圈候选，便宜的模型调用再精选，昂贵的深读只留给最后几页。 |
| 幻觉 | hallucination | 模型一本正经编造不存在的内容或出处——考试不会答还硬编页码。 |
| API 密钥 | API key | 调云端服务时的身份凭证，像门禁卡——随身带，但绝不能写死在要公开的代码里。 |
| base64 |  | 把图片的字节编码成纯文本的办法，让一次请求里能「随身带图」；拼上 data: 前缀就成了内联的数据地址。 |
| 系统提示词 | system prompt | 调用模型时预先给它的岗位说明书，规定角色、任务与输出格式。 |
| 推理强度 | reasoning effort | 模型下笔前「想多深」的档位——批量打标用低档省时省钱，深读分析用高档。 |
| 指数退避 | exponential backoff | 失败重试的节奏：等 2 秒、再败等 4 秒、再败等 8 秒——越挫越客气，不把对方打挂。 |
| JSON 围栏 |  | 模型爱把 JSON 包进三个反引号的代码块再输出，像礼物装了包装盒——解析前要先拆盒。 |
| DPI | dots per inch | 每英寸多少个点，渲染清晰度的旋钮——数字越大图越清楚，进模型的账单也越贵。 |
| 文字层 |  | PDF 里机器可直接抽出的那层文字。真排版的 PDF 有；扫描件只有照片、这层是空的。 |
| 按分辨率计费 |  | 图片进视觉模型按像素量收费的计费方式——图越清晰越贵，清晰度是成本旋钮。 |
| 对半拆批 |  | 一批任务输出超长被截断时，把批对半分成两批递归重试——总能装得下。 |
| 分词 | tokenization | 把连成一串的中文切成可检索的小块——中文没有空格，得自己切（本课程用相邻两字滑窗）。 |
| 停用词 | stop words | 「什么」「怎么」这类到处都有、不携带线索的词，检索前先扔掉。 |
| TF-IDF | term frequency–inverse document frequency | 给词打分的检索方法：在这页出现越多、在全书出现越少的词越值钱。 |
| 词面匹配 |  | 只对字面的检索方式：问「退货」就匹配不到只写「退换」的页——它的盲区正是要加视觉精排的原因。 |
| top-k |  | 只取排分最高的前 k 名——筛候选人筛页面都用它。 |
| 回退 | fallback | 高档手段失败时退回低档手段保命的策略：模型精排失败就退回本地排序，功能不断。 |
| 邻页 |  | 命中页的前后一页。表格和论证常跨页断开，深读要带上邻页才不被半截信息带偏。 |
| 拒答 |  | 证据不足时明确说「资料里没有、缺什么」，而不是编一段——被设计出来的诚实行为。 |
| 正则表达式 | regular expression | 按格式捞文本的渔网：网眼写成「第＋数字＋页」就能从一段话里捞出所有页码引用。 |
| 自包含 HTML |  | 把答案、引用、证据图全部内嵌进单个 HTML 文件——双击即开，不依赖任何外部文件。 |
| 抽帧 | frame extraction | 按固定间隔把视频抽成一张张带时刻标签的图片——视觉模型看视频就是看这叠连环画。 |
| 采样密度 | sampling fps | 每秒抽几帧。抽得密看得清但贵，抽得疏省钱但可能漏掉瞬间——按时长分档权衡。 |
| 场景切换 | scene cut | 画面内容明显突变的时刻（换镜头），可用程序在本地检测出来当切分线。 |
| 段聚合 |  | 把零散的帧卡片按时长归堆成段卡片（如每 30 秒一段），检索粒度从帧升到段。 |
| 运动强度 |  | 帧卡片上顺手记录的「画面动得猛不猛」等级——微观放大层靠它找最值得拉近看的时刻。 |
| 时间戳 | timestamp | 某画面在视频里的时刻，分:秒写作 [01:23]——视频回答里的「页码」。 |
| 关键帧 | keyframe | 能代表一段内容的画面，比如段中间时刻那一帧——一段戏的剧照。 |
| 微观层 |  | 对可疑时间窗用高得多的采样密度（如 12fps）重新看一遍的两级设计——望远镜扫全景、显微镜看疑点。 |
| 中心裁切 | center crop | 把画面中间一块挖出来单独送模型——同样的分辨率下细节翻倍，是「放大看」的实现手段。 |
| 锚点帧 |  | 微观帧序列开头放的一张全图，防止只看放大画面丢失位置感——放大镜旁钉的全景小地图。 |
| 双引擎互验 |  | 同一素材让两个不同厂商的模型各答一遍、对照答案——重要结论问两位专家。 |
| agent skill |  | 写给 AI 助手的工具说明书文件（含触发条件与工作流），让助手在合适的时机自动调用你的脚本。 |
| 渐进披露 | progressive disclosure | 说明书只放一页精要、细节文档按需再读的文档组织法——省上下文预算，像分层抽屉。 |
| 环境变量 |  | 操作系统给每个进程看的随身配置表——密钥这类敏感值放这里，代码里只写名字不写值。 |
| 扫描版 |  | 纸质文档拍照或扫描成的 PDF 页——只有图像没有文字层，机器抽不出字，只能靠看图。 |
| 截断 | finish reason: length | 输出长度超出预算被拦腰砍断——批的答案装不下时的结构性故障，重试救不了，只能拆批。 |
| 文字层兜底 |  | 模型反复读不出的页退而用文字层开头凑一张弱卡占位——整本不中断，弱页事后定向补。 |
| 触发描述 |  | 技能说明头部那段「用户提到 X 且想做 Y 时用本工具」的自然话说明——AI 助手靠它判断何时掏出这个工具。 |
