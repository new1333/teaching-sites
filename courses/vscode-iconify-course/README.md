# 编辑器里的图标智能:VSCode 扩展原理十二讲

一门从零实现的原理课:编辑器怎么认出代码里的图标名、并在旁边画出图标。12 章(3 原理 + 9 动手),每章一个特性、一个真实 bug 故事开章、一个可运行的实验场增量。

## 怎么跑

```bash
# 路 1:从项目根的聚合课程中心进入
pnpm dev

# 路 2:只看本课程
cd courses/vscode-iconify-course
pnpm install
pnpm docs:dev

# 伴生实验场(原理实验工程)
cd companion
npm install
npm test          # 81 条断言
npm run typecheck # tsc --noEmit
```

## 终点里程碑

读完本课程,你拥有一个约 700 行、零编辑器依赖的最小图标智能引擎(TypeScript 库):

- 输入文本与配置,输出带行列范围的装饰描述符(内嵌 data URL 图标与悬停 markdown)、两段式补全项与延迟文档
- 图标数据经三级缓存(内存/磁盘/注入式下载)按需加载并在途去重
- 配置具备最小依赖追踪(ref/computed/watchEffect),改动即自动重算
- 支持本地/远程自定义集合热重载

验证:课程自设的原理断言测试(9 个测试文件、81 条断言)全部通过 + `tsc --noEmit` 零错误。
