# 关于本课程

「编辑器里的图标智能:VSCode 扩展原理十二讲」是一门从零实现的原理课。它回答一个问题:编辑器是怎么认出代码里的图标名、并在旁边画出一枚小图标的?

课程共 12 章、3 个分部(识别 / 数据 / 智能),9 个动手章配一个伴生实验场——一个约 700 行、零编辑器依赖的 TypeScript 库,`tsc` 零错误、81 条原理断言全绿。每章都是「先写测试看到红、再实现转绿、然后才写正文」,正文里的示例代码全部出自实验场。

- **输入**:GitHub 仓库 antfu/vscode-iconify(仅作作者侧备课资料,用于把特性与原理拆对;正文、测试与实验场零仓库痕迹)
- **终点里程碑**:一个最小图标智能引擎——输入文本与配置,输出带行列范围的装饰描述符(内嵌 data URL 图标)、两段式补全项与延迟文档;图标数据经三级缓存按需加载并在途去重;配置具备最小依赖追踪;支持本地/远程自定义集合热重载
- **验证方式**:课程自设的原理断言测试(9 个测试文件、81 条断言)全部通过 + `tsc --noEmit` 零错误

本课程是 teaching-sites 课程中心的一员:项目根目录 `pnpm dev` 从聚合站进入,本课程内 `pnpm install && pnpm docs:dev` 可单独预览。
