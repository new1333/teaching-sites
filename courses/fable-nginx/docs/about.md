# 关于本课程

本课程回答一个主线问题：

> 同一台机器，为什么「一连接一线程」的服务器几千连接就趴下，而 nginx 能扛几万？我们能不能亲手写一个这样的服务器？

全书 7 章、3 个分部，就是这个问题从提出到亲手作答的全过程：先把服务器朴素地写出来（v0、v1），亲眼看到朴素模型的账单；再换上 nginx 的心脏——非阻塞 IO 与事件循环（v2、v3）；最后长成 nginx 的形状（v4 多进程、v5 反向代理），并与真实 nginx 逐项对账。

- **输入**：主题句「nginx 等软件的原理，为什么要存在，怎么复刻一个」（课程生成于 2026-08）
- **形态**：原理重实现课——不复刻 nginx 的源码，而是把它的承重原理亲手重实现一遍；全部实验在本机 127.0.0.1 上完成，Python 3.10+ 纯标准库、零第三方依赖
- **验证物**：`companion/` 是随书演进的迷你 nginx 工程（v0 到 v5 全程可见），56 项行为测试全绿是全书断言的事实源

## 能力阶梯

学到哪一章，你就长出哪一级能力：

- **学完第 1 章**：能凭空写出一个 curl 能访问的 HTTP 服务器，讲清套接字/监听/接受连接与 HTTP 报文的结构，并复现「第二个 curl 干等」
- **学完第 2 章**：能给服务器接上「一连接一线程」并发，用压测探针把每线程内存与上下文切换的账量成本机数字，讲清 C10K 问题与 nginx 的诞生动因
- **学完第 3 章**：能用非阻塞 socket + selectors 写出单线程事件循环服务器，跑出 302 线程对 2 线程的对照实验，解释 select 的上限与 epoll 的模型差异
- **学完第 4 章**：能把 HTTP 解析改造成增量状态机、给连接配收发缓冲，修复掰碎请求读残与大响应截断两起事故，分清水平触发与边缘触发
- **学完第 5 章**：能搭出 master + N worker 的多进程服务器（Windows 上经 spawn 传递监听 socket），实测连接分摊、杀 worker 补位、优雅轮换不断线
- **学完第 6 章**：能写出反向代理：同一事件循环里伺候下游、当客户端连上游，轮询分单、故障摘除，杀一台上游零报错
- **学完第 7 章**：能对照真实 nginx 把每笔差距讲清类别、出处与取舍——哪些是工程优化、哪些是架构差异、哪些是功能缺口

终点里程碑：一个事件驱动、多进程、可反向代理的迷你 nginx（Python 实现，56 项测试全绿）。想再写一遍？走[练习路线](./exercises)。我们对现实的每一处简化都登记在[差异清单](./simplifications)。
