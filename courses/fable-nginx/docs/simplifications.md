# 差异清单：我们对现实的每一处简化

正文每处「我们对现实做了简化/这个平台量不到」的声明集中登记在此，按章列出。更大的差距（sendfile、内存池、TLS、配置系统等）在[第 7 章差距地图](./07-vs-real-nginx)分类对账，本清单管细账。

## 第 1 章 · v0 阻塞服务器

| 简化 | 说明 |
|---|---|
| 一次 recv 当读全、不读正文 | v0/v1 的历史形态；第 4 章 v3 状态机已修复，旧模块按教学原样保留 |
| `/big` 用生成端配速模拟「传输中」窗口 | Windows 回环无写端反压（读端零读取时 256 MB 实测被内核整吞），真实慢写在本机复现不出 |
| 请求行判罚一律 400 | RFC 9112 容许接收方宽容解析；方法大小写、Host 一律不校验（教学取舍） |
| `send_raw` 自动补 CRLF 与空行 | 工具行为，不是协议行为 |
| Windows：主线程阻塞在 `accept()` 时 Ctrl+C 不打断 | KeyboardInterrupt 积压到 accept 返回才落地；横幅「Ctrl+C 停止」在 Windows 的实际行为（第 2 章实验有交代） |

## 第 2 章 · 资源账与切换账

| 简化 | 说明 |
|---|---|
| 交接时延含 GIL | Python 线程共用全局解释器锁，量到的是「本课程跑法里真实的换人成本」，不外推到其他语言 |
| 不数切换次数 | Windows 无标准库口径的每秒切换计数，改测事件乒乓时延与接力环吞吐——量的是什么，账就算什么 |
| 万级数字为线性外推 | 每连接单价是实测的，万级总量是外推的（万条线程本机没有实测）；nginx「2.5 MB/万连接」是官网自报口径，两边口径不对等（正文已注明） |

## 第 3 章 · 事件循环

| 简化 | 说明 |
|---|---|
| Windows 上 DefaultSelector 落到 select | fd 名单实测第 513 个注册报错（1 只监听 + 512 连接即引爆 v2）；万级连接本机挂不上，完整答案在 Linux epoll |
| epoll 行为断言非本机实测 | 全部出自 man7.org 的 epoll(7)/select(2) 文档；本机无 epoll |
| Windows select 拒收空名单 | 实测报 WinError 10022；EventLoop.step 有护栏 |
| v2 一次 sendall 当发全 | 第 4 章 v3 的发送缓冲已修复（历史形态保留在拼版视图） |
| 一问一答即关，无 keep-alive | 全书范围决策：连接处理完即关，keep-alive 不在本课程内实现 |

## 第 4 章 · 状态机与缓冲

| 简化 | 说明 |
|---|---|
| v2 的 sendall 截断事故不可端到端复现 | 单发 64 MB 被内核整吞；真实反压仅在「紧循环分块写」下现身（墙位每次浮动，缩窗后变矮）。复现走三件套：代码形状、内核物理（分块撞墙）、内存微缩内核测试 |
| LT/ET 断言非本机实测 | 出自 epoll(7)；selectors 不暴露边缘触发，本课实现为水平触发 |
| 正文（请求体）不读、行尾只认 CRLF、判罚一律 400 | 最小 HTTP 子集的教学边界（延续第 1 章） |
| `slow_client` 段间「抢答探测」 | 工具行为非协议行为；`--path=big` 值形式兜底 git-bash 的斜杠参数改写 |

## 第 5 章 · master-worker

| 简化 | 说明 |
|---|---|
| accept 惊群未在本机复现 | Windows select 模型下不复现，对照 nginx.org 与 socket(7) 文档讲概念 |
| 优雅重载是触发文件模拟 | 无 POSIX 信号、无配置重读、无 SIGUSR2 二进制升级；轮换的是同一份代码，演示的是「排干退场」的进程语义 |
| spawn 派生慢 | 一两秒/台（Python 官方文档自认 rather slow），轮换窗口比 Unix fork 长一个量级 |
| worker 意外死亡立即补位 | 无退避与次数上限；master 硬死时 worker 一般一秒内退场，但偶发滞留（无硬性退场时限） |
| `X-Fable-Worker` 头、`/status` 路由、fable-stats 账本 | 教学添加，真实 nginx 没有这个头 |

## 第 6 章 · 反向代理

| 简化 | 说明 |
|---|---|
| 每请求一条新上游连接 | 无 keep-alive 上游连接池 |
| 整份响应攒齐才转发 | store-and-forward，真实 nginx 默认流式（proxy_buffering 语义） |
| 请求不带正文 | POST 的 body 不转发 |
| 上游响应必须带 Content-Length | chunked 编码不支持 |
| 无上游超时 | 上游连上不回话则请求挂起（真实 nginx 有 proxy_read_timeout 一族） |
| 无 X-Forwarded-For / X-Real-IP | 仅做 Host 重写 |
| 摘除不自愈 | 划掉不自动放回，重启代理才回名单（真实 nginx 有 max_fails/fail_timeout 恢复节奏，第 7 章对账） |
| Windows 上连接失败约两秒才露头 | 失败连接先沉默、落定后才以写就绪+SO_ERROR 报告（本机三次实测 2.0–2.3 秒，平台行为） |
