# 从零基础小白到A股投资入门

面向零基础开户新手的 A 股技术流课程：看懂 K 线、算清概率、装上风控。22 章正文 + 5 个附录 + 一个可独立运行的最小技术分析引擎（原理实验场）。

- 立场：技术分析是概率与纪律的工具，不是稳赚公式。全书每条形态建议都是条件句 + 失效条件；不构成投资建议。
- 行情数据：全部为固定种子合成行情，由实验场现场算出，零外采数据。

## 怎么跑

```bash
# 方式一：聚合站（项目根目录，可预览全部课程）
pnpm dev

# 方式二：只看本课程
cd courses/a-share-investing-course
pnpm install
pnpm docs:dev
```

## 原理实验场（companion/）

```bash
cd companion
npm install
npm test              # 430 项原理断言测试
npm run typecheck     # tsc --noEmit
npm run export-docs   # 重新产出 docs/assets/data/*.json（固定种子，确定性输出）
```

图表数据再生成：改 `companion/src/` 后跑 `npm run export-docs`，`docs/assets/data/` 全部 JSON 会被重写且两次运行字节一致。

## 章节目录

第一部分 · 地基：看懂市场这台机器
1. 价格为什么会动：股票、交易所与买卖的拔河
2. 一笔订单的旅程：竞价、盘口与挡住你的那些规则

第二部分 · K 线的语言：从一根蜡烛到形态字典
3. 一根 K 线的诞生：从逐笔成交到开高低收
4. 把开高低收画成图：坐标、缩放与 K 线渲染器
5. 单根 K 线（上）：大实体与影线家族的攻防剧本
6. 单根 K 线（下）：十字星家族与「不讲道理」的一字线
7. 双根形态：吞没、乌云盖顶、孕线与平顶平底
8. 三根以上：晨星暮星、三兵三鸦与三法
9. 形态到底灵不灵：用统计给近三十种形态验货

第三部分 · 趋势与量价：给形态装上上下文
10. 趋势的解剖：道氏理论、波峰波谷与画线
11. 均线：把噪声抹掉之后剩下的趋势
12. 成交量：价格是舟，量是水
13. 支撑、阻力与斐波那契：人多的路口，价格会堵车
14. 筹码分布：谁的持仓成本压在哪个价位
15. 头肩顶与双顶：看懂大型反转结构

第四部分 · 指标与概率：MACD、RSI、KDJ、布林带
16. MACD：两条均线的差值能告诉你什么
17. RSI 与 KDJ：超买超卖的双胞胎
18. 布林带与波动率：把概率装进指标

第五部分 · 从看图到下单：风控、回测与交易系统
19. 下单前的最后一道闸：市盈率、市净率与 ROE
20. 期望值与仓位：胜率六成也可能亏钱的数学
21. 最小回测引擎：拿历史数据彩排你的策略
22. 组装你的交易系统：清单、纪律与防骗

附录：术语表 / K 线形态速查表（30 余种）/ A 股交易规则与费用速查表 / 练习路线 / 简化与真实市场差异清单

## 终点里程碑

读完本课程，你拥有一个约三千行的最小技术分析引擎（不含测试约 3000 行，18 个测试文件 430 项断言全绿）：识别近三十种 K 线形态、计算均线/MACD/RSI/KDJ/布林带、跑通含费用与 T+1 的回测；以及一张四栏交易检查清单。零输入体验：所有图表数据由 `npm run export-docs` 现场算出，访客无需自备任何数据。
