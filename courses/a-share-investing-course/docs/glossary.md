# 术语表

本课程首次教过的术语，按出场顺序的自然分组排列；一句话定义都是正文首现时用过的那句话。判据与剧本以各章正文为准，本表用于翻查。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 股票 | stock | 一家公司所有权的一小份凭证，拿着它你就是这家公司的小股东。 |
| A股 | — | 在中国大陆交易所（上交所、深交所、北交所）上市、以人民币交易的中国公司股票。 |
| 交易所 | — | 提供集中撮合买卖的官方市场，中国内地共三家：上交所、深交所、北交所。 |
| 指数 | index | 把一篮子股票的价格加权成一个数，用来看整体市场的冷热，如上证指数、沪深300。 |
| 阴跌 | — | 不声不响、每天跌一点式的下跌：没有大阴线，但一路向下。 |
| 套牢 | — | 买入后价格跌破成本：卖出就坐实亏损、不卖又不甘心的状态。 |
| 多头 | bull / long | 认为价格会涨而买入的一方；买入力量。 |
| 空头 | bear / short | 认为价格会跌而卖出的一方；卖出力量。A股普通账户只能先买后卖，空头是持股的卖出方。 |
| 流动性 | liquidity | 想买时有人卖、想卖时有人买的容易程度；排队的人越多越容易成交。 |
| 盘口 | — | 买方五档出价与卖方五档要价的实时排队表，撮合发生的地方。 |
| 集合竞价 | — | 开盘前 9:15-9:25 集中收一轮买卖申报、按最大成交量原则定出开盘价的机制。 |
| 连续竞价 | — | 开盘后全天持续的逐笔撮合：价格优先、时间优先。 |
| 价格优先时间优先 | — | 撮合排队规则：出价更高的买单先成交、要价更低的卖单先成交；同价先到先得。 |
| 买一卖一 | — | 盘口上最接近成交的一档买价和卖价，两者之差叫价差。 |
| T+1 | — | A股规则：当天买入的股票最快下一个交易日才能卖；资金卖出当天可再用。 |
| 涨跌停 | — | 交易所给当天价格相对昨收盘划的硬边界，超出边报价申报无效；主板±10%（2026年7月起主板ST股同为±10%，此前为±5%）、创业板科创板±20%、北交所±30%。 |
| ST股票 | — | 被交易所标注风险警示的股票（财务或规范出过问题），风险显著更高；2026年7月起主板ST涨跌幅与普通股一致为±10%，此前为±5%。 |
| 打新 | — | 申购新上市的股票：中签后按发行价买入，上市首日择机卖出；参与者须持有一定市值的股票，规则以交易所最新发布为准。 |
| 手 | — | A股的买卖单位，1手=100股；买入必须以手的整数倍，卖出可以有零股。 |
| 印花税 | — | 卖出股票时交给国家的税，当前为成交金额的0.05%（买入不收）。 |
| 佣金 | — | 交给券商的手续费，买卖双向收取，常见万分之一到万分之三，通常单笔最低5元。 |
| K 线 | candlestick | 把一段时间内的开盘价、收盘价、最高价、最低价画成一根蜡烛状图形的价格记录。 |
| 开高低收 | OHLC | 一段时间内的开盘价、最高价、最低价、收盘价，一根K线的四个原始数据。 |
| 实体 | body | K线中开盘价到收盘价的粗段，代表这段时间多空拉锯后的净结果。 |
| 影线 | wick / shadow | K线实体上下伸出的细线，上影线摸过最高价、下影线探过最低价，记录盘中被反击回去的攻防。 |
| 阳线 | — | 收盘价高于开盘价的K线（A股软件默认画成红色）：当天买方把价格抬过了开盘价。 |
| 阴线 | — | 收盘价低于开盘价的K线（默认绿色）：当天卖方把价格压破了开盘价。 |
| 分时图 | — | 把当天每分钟成交价连成一条线的图，是日K线背后那一天的『显微镜视图』。 |
| 周期聚合 | — | 把小周期K线合并成大周期：周K线的开=本周第一根日K的开、收=最后一根的收、高=最高的高、低=最低的低。 |
| 除权除息 | — | 分红送股后交易所把股价按规则调低（你的账户补上现金或股票，总资产不变）；不调低，白送的份额就成了凭空多出的市值。 |
| 价格坐标系 | — | 把最高价到最低价的区间映射成画布高度的规则：纵轴区间不同，同一根K线的长相不同。 |
| 对数坐标 | — | 按涨跌幅百分比而不是价格绝对值刻画的纵轴：同样幅度的涨跌画得一样高，看长期图用它。 |
| 成交量副图 | — | K线主图下方独立画成交量的条形图：量与价各用各的坐标，互不挤占。 |
| 归一化 | — | 把不同量纲的序列各自缩放到自己的坐标里：副图的量再大也不改变主图的价格刻度。 |
| 复权 | — | 把分红除权造成的价格跳空修补回连续序列的方法，看长期图必开前复权，否则形态全是假的。 |
| 大阳线 | — | 实体特别长的阳线：买方从开盘压到收盘的全场大胜。 |
| 大阴线 | — | 实体特别长的阴线：卖方从开盘压到收盘的全场大胜。 |
| 锤子线 | hammer | 长下影、小实体的单根K线：盘中被深砸但收盘收了回来，显示下方出现强承接。 |
| 上吊线 | hanging man | 形状与锤子线相同但出现在上涨之后：同样的图，位置不同，含义反转。 |
| 射击之星 | shooting star | 上涨后的长上影小实体K线：向上冲锋被当场打了回来，上方抛压的实弹测试。 |
| 倒锤子 | inverted hammer | 下跌后的长上影小实体：第一次认真试探上方抛压，收阳确认才有意义。 |
| 光头光脚 | — | 没有影线的K线：开盘即一路单边到收盘，一方全天压着打。 |
| 十字星 | doji | 开盘价≈收盘价、只剩影线的K线：多空打了一天打成平手，常是变盘前兆。 |
| 长腿十字 | long-legged doji | 上下影都特别长的十字星：巨大的分歧，两边都被推翻过一次。 |
| 蜻蜓线 | dragonfly doji | 开盘收盘都贴着最高点的长下影十字：全天砸下去又被全额买回。 |
| 墓碑线 | gravestone doji | 开盘收盘都贴着最低点的长上影十字：冲高的买盘全军覆没。 |
| 一字线 | four-price doji | 开=高=低=收四价合一：一字板，想买买不到、想卖卖不掉。 |
| 纺锤线 | spinning top | 实体影线都小的K线：多空都无意恋战，市场在打盹。 |
| 吞没形态 | engulfing | 今天的实体把昨天实体整个包住：今天的胜方不只是赢，还把昨天的战果整个收回。 |
| 乌云盖顶 | dark cloud cover | 上涨后高开却收在昨天实体中点之下的阴线：高开是最后的乐观，收不回去是反转信号。 |
| 刺透形态 | piercing | 下跌后低开却收进昨天阴线实体中点之上：恐慌盘被低位买盘正面顶回。 |
| 孕线 | harami | 今天的小实体整个缩在昨天大实体之内：攻势骤然踩了刹车，市场在犹豫。 |
| 十字孕线 | doji harami | 昨天大实体、今天十字星缩在其内：犹豫到极致，常是变盘前夜。 |
| 平顶 | tweezer top | 两根相邻K线的高点几乎落在同一价位：同一个位置两次证明上方有人守。 |
| 平底 | tweezer bottom | 两根相邻K线的低点几乎落在同一价位：同一个位置两次证明下方有人撑。 |
| 早晨之星 | morning star | 下跌末端『大阴+小实体星线+跳涨阳线』三根组合：卖压枯竭、买方接管的完整剧本。 |
| 黄昏之星 | evening star | 上涨末端『大阳+星线+跳跌阴线』：早晨之星的镜像，涨势熄火剧本。 |
| 红三兵 | — | 连续三根温和递进的小阳线：上涨按节奏推进，没有剧烈反扑。 |
| 黑三鸦 | — | 连续三根温和递进的小阴线：下跌按节奏推进，没有像样的反弹。 |
| 红三兵受阻 | — | 红三兵之后紧跟高位小实体或长上影：推进撞上了墙的警示。 |
| 上升三法 | rising three methods | 上升趋势的五根中继组合：一根大阳线、三根缩在其影线范围内的小回撤、再一根同向大阳线——歇脚不折返。 |
| 下降三法 | falling three methods | 下降趋势的五根中继组合：一根大阴线、三根缩在其影线范围内的小反弹、再一根同向大阴线——歇脚不折返。 |
| 样本量 | — | 统计里的有效次数：样本太少，再高的胜率也可能只是运气。 |
| 随机对照 | — | 把同一形态放到随机打乱的行情里再统计一遍当对照组：比出来的优势才算数。 |
| 基准概率 | — | 不看任何信号、随便找个日子买入并持有同期的胜率：形态胜率必须和它比才有意义。 |
| 趋势 | trend | 价格留下的方向性足迹：更高的高点和更高的低点不断出现就是上升趋势。 |
| 道氏理论 | Dow theory | 查尔斯·道留下的趋势分析框架：趋势由波峰波谷的方向定义，且分主要/次级/日间三级。 |
| 趋势线 | — | 连接依次抬高的回撤低点（或依次降低的反弹高点）的直线：给趋势画出的边界。 |
| 通道 | — | 把趋势线平移到对侧波峰得到的平行轨道：趋势沿它行驶的路。 |
| 均线 | moving average, MA | 最近N天收盘价的滑动平均，把噪声抹掉只留趋势的平滑线。 |
| 指数移动平均 | EMA | 给越新的价格越大权重的均线，对最新变化反应更快但仍滞后。 |
| 金叉 | — | 短期均线上穿长期均线：短期共识转向乐观的迟到信号。 |
| 死叉 | — | 短期均线下穿长期均线：短期共识转向悲观的迟到信号。 |
| 动量与均值回归 | — | 两种市场观：涨的会继续涨（追趋势），涨多了会回来（做回归）；均线类策略默认前者。 |
| 成交量 | volume | 一段时间内实际成交的股数，衡量参与度和分歧度：有人卖还得有人买才算成交。 |
| 换手率 | — | 成交量除以流通股本，今天有多少百分比的筹码换了主人。 |
| 量价背离 | — | 价格创新高/新低而成交量萎缩：推进的燃料不足，趋势可疑。 |
| 地量 | — | 一段时间里最小的成交量：愿意卖的暂时卖光了，常出现在下跌的尾声。 |
| 天量 | — | 一段时间里最大的成交量：分歧最剧烈的一天，天量之后常有天价。 |
| 支撑 | — | 历史上买方挂单反复扎堆的价格区间下沿：跌到有人接的位置。 |
| 阻力 | — | 历史上卖方挂单反复扎堆的价格区间上沿：涨到有人抛的位置。 |
| 枢轴点 | pivot | 局部的高点或低点拐角，画趋势线和支撑阻力的原材料。 |
| 假突破 | false breakout | 价格刺破支撑/阻力后又迅速收回：专门收割止损盘和追单的走势。 |
| 锚定效应 | — | 人把最近见过的价格当参照点的心理偏差：整数关口、前高前低因此自带魔力。 |
| 斐波那契回调 | Fibonacci retracement | 在一段涨跌幅上按0.236/0.382/0.5/0.618等比例画的潜在回撤刻度：信的人多了，刻度本身成了路口。 |
| 筹码分布 | chip distribution / CYQ | 估算每个价位上还压着多少持仓量的图：山峰=拥挤的历史成本区，获利盘/套牢盘比例由它算出。 |
| 头肩顶 | head and shoulders | 中间高点更高的三峰结构与颈线：涨势三次冲顶、两次回撤后买方接力枯竭的经典反转结构。 |
| 双顶 | double top | 两次冲击同一价位失败形成的M形顶：同一个位置两次证明卖压迫得住。 |
| 双底 | double bottom | 两次砸到同一价位都被买起的W形底：同一个位置两次证明买承接得住。 |
| 颈线 | neckline | 头肩/双顶结构中连接回撤低点的参考线，跌破它才算结构成立。 |
| 量度目标 | — | 形态成立后按结构高度推算的最小涨跌幅度：颈线距离的等幅投影。 |
| 缺口 | gap | 两根K线之间没有任何成交的价格真空区，常由隔夜消息或情绪跳空造成。 |
| MACD | — | 两条不同周期EMA的差值及其平滑线的组合指标，用来度量动量的方向与衰减。 |
| 背离 | divergence | 价格创新高/新低而指标拒绝跟随：推着价格走的燃料与价格本身唱反调。 |
| RSI | relative strength index | 最近一段上涨幅度占全部波动的百分比：衡量买方力量的持久度，而非超买超卖开关。 |
| KDJ | stochastic oscillator | A股软件默认的摆动指标：收盘价在近期高低区间的位置（RSV）经两次平滑，对价格变化极敏感。 |
| 布林带 | Bollinger bands | 均线±若干倍标准差构成的三条带：用波动率而不是固定百分比画的弹性通道。 |
| 标准差 | standard deviation | 衡量一组数离平均数平均有多远的量，价格波动的『颠簸幅度』。 |
| 正态分布 | — | 「两头少、中间多」的钟形波动直觉：价格波动比它尾巴更肥，±2σ 不是铁地板。 |
| 胜率 | — | 盈利交易次数占全部交易次数的比例，单独看没有意义，必须配盈亏比。 |
| 盈亏比 | — | 平均每笔盈利金额与平均每笔亏损金额之比。 |
| 期望值 | expectancy | 胜率×平均盈利−败率×平均亏损：长期平均每次交易的期望盈亏。 |
| 止损 | stop loss | 进场前就定好的认输价位：单次亏损的硬上限，让错误变得廉价。 |
| 条件单 | — | 提前告诉券商「价格触到 X 就替我卖出/买入」的预埋指令；A股没有交易所原生的止损单，靠券商 App 的条件单实现。 |
| 仓位 | position sizing | 一笔交易投入的资金比例；决定错了多痛、对了多赚的旋钮。 |
| 凯利公式 | Kelly criterion | 按胜率与盈亏比算出的最优下注比例公式；实战取其分数，因为参数是估计值。 |
| 破产风险 | risk of ruin | 连续亏损把本金打到无法继续（或心态崩溃）的概率；仓位越重、盈亏比越差越高。 |
| 回测 | backtest | 用历史数据按规则彩排交易、统计成绩的实验方法。 |
| 未来函数 | — | 回测里用了当时不可能知道的数据（如用收盘价决定当天开盘买入）：偷看答案，胜率虚高。 |
| 过拟合 | overfitting | 把历史噪声当规律背下来：参数调到历史完美，遇到未来就碎。 |
| 幸存者偏差 | survivorship bias | 只用活到今天的样本做统计，退市股、爆雷股不在样本里，结论偏乐观。 |
| 最大回撤 | max drawdown | 账户从历史最高点到之后最低点的最大跌幅：最深那次下坡有多疼。 |
| 滑点 | slippage | 预期成交价与实际成交价的差，急市里按市价吃单要多付的成本。 |
| 市盈率 | PE | 股价÷每股盈利：按现在的利润，几年回本；衡量市场给公司多少倍溢价。 |
| 市净率 | PB | 股价÷每股净资产：价格是家底的几倍；银行等重资产行业常用。 |
| ROE | — | 净资产收益率：公司拿股东的钱一年能赚回百分之几，长期赚钱能力的核心指标。 |
| 股息率 | dividend yield | 近 12 个月每股分红÷现股价：长期投资回报里「分红」那一块的年化读数。 |
| 损失厌恶 | loss aversion | 同样数额的亏损带来的痛感约等于两倍数额盈利的快感：处置效应的心理学地基。 |
| 处置效应 | disposition effect | 赚一点急着落袋、亏了死扛不认账的行为偏差：拔鲜花、浇野草。 |
| 交易系统 | — | 把入场、止损、仓位、离场写成可执行清单的完整规则集，作用是替你挡住盘中情绪。 |
