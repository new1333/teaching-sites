# 关于本课

这门课从一句主题句长出来：「从零基础小白到A股投资入门」，技术流主线。全部 22 章正文、5 个附录、以及一个可独立运行的最小技术分析引擎（companion 实验场，约三千行 TypeScript，430 项原理断言测试）由课程管线逐章生成、逐章评审。

**立场**：技术分析是一套概率与纪律的工具，不是稳赚公式。本课程教的是「看懂盘面语言 + 用统计思维验证 + 用风控活着」；每条形态建议都以条件句给出并写明失效条件。历史规律不保证未来，本课程不构成投资建议。

**输入**：主题句（无参考仓库）。**行情数据**：全部为固定种子合成行情，由实验场 `npm run export-docs` 现场算出，正文与图表零外采数据。

**怎么跑**：见课程根目录 README（聚合站 `pnpm dev` 或本课程 `pnpm docs:dev`）。
