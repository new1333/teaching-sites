三月里那只票你是追进去的。它从 8 元附近一路涨到 15 元上方，横了两周，某天收盘 MA5 从下往上穿过了 MA20——群里瞬间刷屏：金叉了，第二波启动。你当天尾盘买入。此后三天确实又冲高一点，然后掉头。你安慰自己「死叉没出就是趋势没完」，一路拿到死叉出现那天才离场：距离山顶已经过去八个交易日，价格从最高的 15.32 元跌到 13.46 元，回吐 12%。这笔账里最扎心的不是亏钱，是位置：金叉一出就买入的你，买在山顶附近，替涨势的最后一棒接了盘——不对，接盘侠的说法更准。

问题不在金叉说谎。金叉说的是真话，只是句句慢半拍：它必须等短期价格真涨过一截、把五天平均拽到二十天平均之上，才开口确认。等它开口，涨势常常已经走完大半。慢半拍不是主力跟你作对，是均线的算术里写死的——本章要把这笔算术亲手算一遍：慢半拍从哪来、窗口越长为什么越慢、指数移动平均打了什么补丁。最后回答真正的问题：一个永远迟到的信号，怎么用才不当接盘侠。

## 均线：最近 N 天收盘价的滑动平均

第 10 章给趋势下定义，靠的是波峰波谷——只在拐角处读方向。那条路线稀疏：拐角要左右各几根 K 线陪衬，认出来时它已经是历史。均线（moving average，MA——最近 N 天收盘价的算术平均、每天随新收盘价滚动重算的那条平滑线）是稠密路线：每一根 K 线都算一次平均，天天有读数。

为什么平均能抹掉噪声？把单日收盘价拆开看：方向加噪声。方向每天同号，累加后保留；噪声有正有负，窗口内互相抵消。窗口越长，抵消得越干净，线越平滑——代价后面再算，先跟着算一遍。取本章第一张图的真实数据，合成行情的前五根收盘价是 10.13、10.24、10.18、10.30、10.33 元。五日均线 MA5 在第 5 根才成形：

```text
MA5（第5根）= (10.13 + 10.24 + 10.18 + 10.30 + 10.33) ÷ 5 = 51.18 ÷ 5 = 10.236 ≈ 10.24 元（图上按分显示）
```

第 6 根收盘后，窗口右移一格：进一根新的，退一根最老的，再除以 5。二十日均线 MA20 同理，但要攒够 20 个收盘价——图上它的前 19 个位置是空白，数据里记 null，第 20 根才落下第一个值 10.83 元。这不是缺陷，是如实：窗口不足时均线不存在，代码里也不许猜。

噪声天天有，两条均线只留方向。MA5 贴着价格，MA20 迟缓但笃定，从 10 元附近爬到 16 元上方，末端两者分别是 17.19 元与 16.01 元。市场里常把均线读作「最近 N 天买入者的平均成本」：价格站在 MA20 上方，近 20 天进场的人平均赚钱，抛压相对温和。这只是常用的读法，不是物理事实。它的量化版——乖离（价格偏离均线多远）怎么量——第 18 章再回来。

## 金叉死叉：两条均线的分岔口

短窗口均线对价格敏感，长窗口均线迟钝。两条线画在一起，交叉处就成了信号：金叉（golden cross——短期均线从下往上穿过长期均线，大白话是「最近五天的共识追上了最近二十天的共识」）；死叉（dead cross——短期均线从上往下跌破长期均线，短期共识转冷）。实验场记账的口径是严格穿越：前一根快线不高于慢线、这一根严格高于，才算金叉；两根贴着相等，不算。A 股软件默认的 MA5/MA20 指的就是这类简单平均线。

## 慢半拍从哪来：一笔算得清的账

滞后不是玄学，是除法。均线在每个时刻都装着 n 个收盘价，其中最新的那个只占 1/n。跟着算一遍，用五根收盘价的小样本，第 5 根从 10 跳到 13：

```text
收盘价：      10    10    10    10    13
MA3：                     (10+10+13) ÷ 3 = 11.00
MA5：                     (10+10+10+10+13) ÷ 5 = 10.60
```

新价格 13 出现的那一根，MA3 差 2 元没跟上，MA5 差 2.4 元——窗口越长，新价的话语权越小。再往后看：若收盘价从此全是 13，MA3 再走两根到位（11 → 12 → 13），MA5 要再走四根（10.6 → 11.2 → 11.8 → 12.4 → 13.0）。机理只有一句：**均线里永远拖着旧价格，反转时它必须等新价格把旧价格一根一根顶出窗口**。窗口翻倍，迟到大约也翻倍。金叉更狠：它要的不是均线追上价格，是短均线追上长均线——迟到的平方。

指数移动平均（EMA，exponential moving average——给越新的价格越大权重、权重按指数衰减的均线）是给这笔账打的补丁。它没有硬窗口，递推一句话：新一格 = 旧值 + α ×（新收盘价 − 旧值），α = 2 ÷ (n+1)。新价格每次只能把均线拽动「差距 × α」那么远。跟着算：n = 3 时 α = 0.5，收盘价 10、10、10 之后跳到 13——首窗平均 10 作种子，第四格 = 10 + 0.5 × (13 − 10) = 11.5。比同位置 MA3 的 11 更靠近 13，但没到。**快了一点，慢的本质没变。**

把补丁放到 n = 20 上量一量：收盘价 10 元横走 30 根，一步跳到 13 元，两条均线各自追。

<LineChart :series="resp.series" :labels="resp.labels" title="跳价之后：EMA20 与 SMA20 的追赶速度" />

快慢立刻分了出来。「追到跳幅一半」（≥ 11.5 元）这条线，EMA20 用了 7 根，SMA20 用了 10 根。也如实报另一面：到跳变后第 20 根，SMA20 恰好收在 13.00——硬窗口彻底换血，旧价格全部退场；EMA20 还停在 12.59，指数权重让旧价永远残留一点。前段 EMA 快，末段 SMA 追平。**两条线谁也消灭不了滞后，只能分配它。**

## 两种市场观：动量与均值回归

均线交叉为什么值得一看？背后是一种对市场的看法。动量（momentum——跑起来的东西倾向于继续跑的市场观：近期涨的会再涨一段，趋势有惯性）；均值回归（mean reversion——离家太远总会回家吃饭的市场观：价格偏离平均越远，往回拉的力量越强）。金叉死叉是纯动量工具：它假设趋势一旦启动就有惯性，用「短期平均追上长期平均」确认惯性已在。可若此刻的市场是均值回归主导的震荡市，短线涨多了本来就该回家，你却按动量逻辑在金叉处追进去——买在波段顶部。开章那笔「翻倍后横盘再追金叉」，多半就是这种错配。**工具没错，错的是不带市场观地用工具。**

图二第 22 根那个横盘期假死叉，就是震荡市鞭打均线的样子。过滤它靠上下文，不必发明新工具：用第 10 章的定义数一数——横盘期峰谷混杂，按定义没有趋势，趋势工具就地停用；波峰波谷成链了，均线的读数才值得听。

### 葛兰碧八法：一张点到为止的表

均线普及的年代，美国技术分析人士葛兰碧（Joseph Granville）把价格与单条均线的关系总结成八条法则，四买四卖：

| 编号 | 情形 | 动作 |
| --- | --- | --- |
| 买一 | 均线走平后转向上，价格从下上穿均线 | 买 |
| 买二 | 价格跌破均线，但均线仍向上，很快收回 | 买 |
| 买三 | 价格回踩均线附近，未破而获支撑反弹 | 买 |
| 买四 | 价格急跌、远离均线（超跌） | 买 |
| 卖一 | 均线走平后转向下，价格从上下穿均线 | 卖 |
| 卖二 | 价格上破均线，但均线仍向下，随即跌回 | 卖 |
| 卖三 | 价格反弹到均线附近受阻回落 | 卖 |
| 卖四 | 价格急涨、远离均线（超涨） | 卖 |

表点到为止，不展开。八条里「走平」「远离」都是还没量化的词，数值化是后面指标章的事：乖离怎么算、拿什么当「远」的尺，第 18 章布林带接手。表内八条本章不做数值化，实验场实现的是另一种严格可计算的均线关系——双均线交叉。

## 慢半拍的用法：等回踩与多周期过滤

回到开章的问题：一个永远迟到的信号，怎么用？**金叉是趋势的迟到确认，不是起跑的枪声。**把它当确认器，两条常见做法，都以条件句写出。

其一，等回踩确认，不追第一根金叉。若金叉出现后价格回踩 MA20 附近（或金叉前的突破位）、收盘不破且再度转涨，常见的应对是在企稳处进场，止损放在回踩低点下方一点；失效条件是回踩直接收盘跌破 MA20，或随后走出死叉——触发即放弃这个信号。用几根 K 线的耐心，换掉「买在山顶」的整段风险；代价是干脆利落的强势行情会踏空，位置从来不是免费的。

其二，多周期过滤：日线金叉只在更大周期趋势同向时才当有效信号。用第 3 章的周期聚合把日 K 并成周 K，再用第 10 章的定义数周线峰谷——若周线 HH 与 HL 链完好，日线金叉常见的应对是当趋势内的一次进场机会处理；失效条件是周线 LH 与 LL 链未断，那种情况下的日线金叉一律只当反弹看待，不追。级别钉死了，慢半拍的鞭子就抽不到你。两条做法共用一个前提：不找「不慢的线」，那东西不存在——把仓位和节奏安排得配得上它的迟到。

## 渐进实验：先让命题见红

老规矩，先写测试看红。本章测试审五件事：sma 滑窗与手算逐格一致；ema 递推与手算一致；头部不足窗口返回 null 且数组与 K 线等长；金叉死叉位置与手算一致；新价格跳变后 ema 响应快于 sma、且窗口越长追得越慢。挑核心的三条贴出来。第一条，交叉位置：

```ts
// tests/moving-averages.test.ts · 金叉死叉位置与手算一致
  it('平走→抬升→回落：金叉@8、死叉@11，与逐格手算一致', () => {
    const closes = [...Array(8).fill(10), ...Array(3).fill(12), ...Array(4).fill(8)]
    const r = crossovers(seriesFromCloses(closes), 2, 3)
    expect(r).toEqual([
      { index: 8, kind: 'golden' },
      { index: 11, kind: 'dead' },
    ])
  })
```

这段序列逐格手算：前八根平走，MA2 与 MA3 都贴在 10；第 9 根（下标 8）收盘跳 12，MA2 = 11 越过 MA3 = 10.67，金叉；随后三个 12 让 MA3 追平；第 12 根（下标 11）收盘跌回 8，MA2 = 10 跌破 MA3 = 10.67，且前一根 12 恰好贴着 12——按「前一根不低于」的口径，死叉成立。第二条，响应速度：

```ts
// tests/moving-averages.test.ts · ema 对新价格响应更快
  it('ema 比 sma 更快朝新价格靠拢：13.33 对 12，都还差得远（这就是慢半拍）', () => {
    const e = ema(jump, 5)
    const s = sma(jump, 5)
    expect(s[29]).toBeCloseTo(12, 10)
    expect(e[29]).toBeCloseTo(10 + (1 / 3) * 10, 10)
    expect(e[29]!).toBeGreaterThan(s[29]!)
    expect(20 - e[29]!).toBeLessThan(20 - s[29]!)

```

jump 序列是 29 根收盘 10 元、最后一根跳 20 元：n = 5 时 SMA 末格 = (4×10 + 20) ÷ 5 = 12，EMA 末格 = 10 + (2/6) × 10 ≈ 13.33。都还远着——慢半拍的量化像。第三条，窗口越长越慢：

```ts
// tests/moving-averages.test.ts · 窗口越长慢得越重
  it('窗口越长慢得越重：同一次跳变，sma(5) 走到 12，sma(10) 只走到 11', () => {
    const s5 = sma(jump, 5)
    const s10 = sma(jump, 10)
    expect(s5[29]).toBeCloseTo(12, 10)
    expect(s10[29]).toBeCloseTo(11, 10)
    expect(s5[29]!).toBeGreaterThan(s10[29]!)
  })
```

见红后实现。新模块 `src/indicators/ma.ts`，先立字据：均线序列与 K 线逐根对齐，头部不足窗口的格子是 null。

```ts
// src/indicators/ma.ts · 均线序列与交叉信号的类型
/** 均线序列：与入参 K 线等长、逐根对齐；头部不足一个窗口的格子是 null——均线还没成形 */
export type MaSeries = (number | null)[]

/** 一次交叉：金叉=快线上穿慢线，死叉=快线下穿慢线 */
export type MaCross = {
  /** 交叉成立的 K 线下标——这一根收盘算完，快线与慢线刚分出高下的那一刻 */
  index: number
  /** golden=金叉（前一根快线不高于慢线、这一根严格高于）；dead=死叉（前一根不低于、这一根严格低于） */
  kind: 'golden' | 'dead'
}
```

三个公共入口共用一段入参体检，与第 9 章 evaluate 的体检同款。体检名单：空序列、非正整数窗口、非有限收盘价，当场抛中文错误。sma 全貌如下，滑窗只做一加一减。

```ts
// src/indicators/ma.ts · sma 全貌
/** 简单移动平均：最近 n 个收盘价的算术平均。滑窗只做一加一减，整条均线每个格子都是真平均 */
export function sma(candles: readonly Candle[], n: number): MaSeries {
  assertMaArgs(candles, n, 'sma')
  const out: MaSeries = new Array(candles.length).fill(null)
  if (candles.length < n) return out // 不足一个窗口：整条都是 null，不猜
  let sum = 0
  for (let i = 0; i < candles.length; i++) {
    sum += candles[i].close
    if (i >= n) sum -= candles[i - n].close // 窗口右移一格：进一根新的，退一根最老的
    if (i >= n - 1) out[i] = sum / n
  }
  return out
}
```

ema 全貌如下。首窗 SMA 作种子，此后每根只按 α 挪一步。

```ts
// src/indicators/ma.ts · ema 全貌
/** 指数移动平均：给越新的价格越大的权重，反应比 sma 快、但仍滞后。
 *  第一个值取首窗 n 个收盘价的 sma 作种子，此后每根递推：
 *  ema[i] = ema[i−1] + α × (close[i] − ema[i−1])，α = 2 ÷ (n+1)。 */
export function ema(candles: readonly Candle[], n: number): MaSeries {
  assertMaArgs(candles, n, 'ema')
  const out: MaSeries = new Array(candles.length).fill(null)
  if (candles.length < n) return out
  const alpha = 2 / (n + 1)
  let seed = 0
  for (let i = 0; i < n; i++) seed += candles[i].close
  let prev = seed / n
  out[n - 1] = prev
  for (let i = n; i < candles.length; i++) {
    prev = prev + alpha * (candles[i].close - prev) // 新价格只按 α 拽动均线一步，剩下的 (1−α) 是历史惯性
    out[i] = prev
  }
  return out
}
```

crossovers 全貌如下。快慢两条 SMA 逐格比较，严格穿越才记账。

```ts
// src/indicators/ma.ts · crossovers 全貌
/** 金叉死叉扫描：快慢两条 sma 的逐格比较，返回全部交叉信号（按时间旧→新）。
 *  A 股软件里默认的 MA5/MA20 金叉死叉就是它。窗口口径取 sma（与行情软件默认一致），
 *  要比 ema 快慢线，把两条 MaSeries 自己比一遍即可，口径先声明。 */
export function crossovers(candles: readonly Candle[], fast: number, slow: number): MaCross[] {
  if (!Number.isInteger(fast) || fast < 1) {
    throw new Error(`crossovers：fast 必须是正整数，收到的是 ${fast}`)
  }
  if (!Number.isInteger(slow) || slow < 1) {
    throw new Error(`crossovers：slow 必须是正整数，收到的是 ${slow}`)
  }
  if (fast >= slow) {
    throw new Error(`crossovers：fast 窗口必须短于 slow（收到 fast=${fast}、slow=${slow}）——快慢线比的是谁窗口短`)
  }
  if (!Array.isArray(candles) || candles.length === 0) {
    throw new Error('crossovers：candles 不能为空')
  }
  if (candles.length <= slow) {
    throw new Error(`crossovers：序列至少要 ${slow + 1} 根K线才凑得出相邻两个慢线值，收到的是 ${candles.length} 根`)
  }
  const fastMa = sma(candles, fast)
  const slowMa = sma(candles, slow)
  const out: MaCross[] = []
  // 循环从 slow 起步：i 与 i−1 都 ≥ slow−1，两条均线在这些格子必然已成形（滑窗算术保证，不是猜）
  for (let i = slow; i < candles.length; i++) {
    const fPrev = fastMa[i - 1]!
    const sPrev = slowMa[i - 1]!
    const fNow = fastMa[i]!
    const sNow = slowMa[i]!
    if (fNow > sNow && fPrev <= sPrev) out.push({ index: i, kind: 'golden' })
    else if (fNow < sNow && fPrev >= sPrev) out.push({ index: i, kind: 'dead' })
  }
  return out
}
```

循环里那些叹号是 TypeScript 的非空断言：循环从 slow 起步，数学上保证取到的格子必然已成形，注释里写清了依据。图表数据照旧出自 export-docs 脚本，图二的标记是真实扫描：

## 小结

- 均线是最近 N 天收盘价的滑动平均：噪声在窗口内互相抵消，方向留下。窗口越长越平滑，也越迟钝。
- 滞后是算术：最新价格只占窗口的 1/n，反转时均线要等新价把旧价一根根顶出窗口。EMA 给新价更大权重，快一点，慢的本质不变。
- 金叉死叉是短期均线对长期均线的严格穿越：趋势的迟到确认，不是起跑枪。死叉常比山顶晚一截，其间利润回吐可观。
- 动量观读均线为趋势确认，均值回归观读为偏离度；震荡市里交叉被反复打脸，先用第 10 章的定义钉住有无趋势再决定听不听它。
- 迟到信号的用法两条：等回踩确认再进，收盘破 MA20 或再死叉即弃；多周期过滤，周线 LH 与 LL 链未断时日线金叉只当反弹。

读完本章，你应该能回答：

1. 收盘价 10、10、10、10、13——MA3 与 MA5 各是多少？哪个离新价更远？为什么？
2. n = 3 的 EMA 种子是 10，新收盘价 13——下一格 EMA 是多少？比同位置的 MA3 快多少？
3. 一段行情金叉在第 27 根、山顶第 52 根、死叉在第 60 根——「拿着等死叉离场」在这段里付了什么代价？若金叉出现在第 50 根附近呢？
4. 周线 LH 与 LL 链完好时冒出日线金叉，按本章的规则怎么处理？失效条件是哪两条？

去向一句话：均线把趋势变成一条天天更新的线，下一章把成交量加进来——价格是舟、量是水，趋势的燃料够不够要另算一笔；而两条 EMA 的差值能长出什么，第 16 章的 MACD 接力。
