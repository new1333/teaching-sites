三月底，群里有人发了张截图：「这只票出锤子线了——长下影、小实体，教科书级的见底信号。」（锤子线：盘中深砸、收盘收回来的 K 线，因图形像一把锤子得名。）这只票你已经盯了两周，从 18 块跌到 12 块出头，那天分时确实砸出一个深坑又拉了回来。第二天开盘你追了进去，两周后账户浮亏一成。复盘时你把那根 K 线的四价抄下来算了一遍：开 12.30、高 12.32、低 11.60、收 12.00。下影 0.40 元，实体 0.30 元——下影只有实体的 1.33 倍，任何一家教科书都要求「至少两倍」，这根从头到尾够不上锤子。再往前看，它出现在下跌的第三周中段，前后没有止跌的任何旁证。**页边印着「见底信号」四个大字，真正的判据藏在正文小字里，而你只看了大字。**

这一章把小字变成代码。我们要给七种单根形态写出数值判据：大阳线、大阴线、光头光脚、锤子线、上吊线、射击之星、倒锤子。判据只读第 3 章解剖器 `candleAnatomy` 量出的数字，不读像素长相。第 4 章已经证明纵轴缩放会骗过眼睛，骗不过除法。更重要的是一条贯穿全章的规则：**形状 × 位置 = 含义**。同一根长下影 K 线，出现在一段下跌之后叫锤子线，出现在一段上涨之后叫上吊线，名字反过来，剧本也反过来。位置不是形状的注脚，是名字的一半。

## 一根 K 线是一天的攻防记分牌

先把第 3 章的读数搬过来：实体是开盘到收盘的距离，当天的净战果；上影线是多边冲上去、空头又打回来的那段，下影线是空方砸下去、多头又接回来的那段。影线记录的不是「价格去过哪」，而是「谁发起过进攻、这次进攻的结局」。长影线是一次被实测过的强攻——发起、得手、又被全额击退，全程发生在一天之内。

所以每种形态都可以翻译成一部当日剧本：谁先动手、打到哪、谁守住了、收盘的比分说明什么。下面每一节都按同一个次序讲：剧本、数值判据、位置条件、以及一条带失效条件的应对句式。应对句式是全课程的统一纪律：出现 X 且满足 Y 时，常见的应对是 Z，失效条件是 W——没有失效条件的建议等于没有建议。

## 大阳线与大阴线：一边倒的比分

剧本：大阳线（实体特别长、几乎不带影线的阳线——一方从开盘压到收盘的全场大胜）的当天是这样的：开盘哨响，多方报价一路抬高，空头每次反扑都小得在图上留不下痕迹，收盘价接近全天最高。大阴线是镜像：空头从开盘杀到收盘，多头连一次像样的反攻都没组织起来。这两根 K 线不讲故事转折，它们记录的是控制权——这一天从头到尾归谁。

数值判据：实体占全天振幅的比例（第 3 章的 `bodyRatio`）不低于 0.7。跟着算一遍：开 10.00、收 10.75、高 10.80、低 9.95，实体 0.75 元，振幅 0.85 元，占比 88%，大阳线成立。换一组：开 10.00、收 10.66、高 10.66、低 9.66，实体 0.66、振幅 1.00，占比 66%——差四个百分点，不叫「大」。判据定在七成是本课程的操作化选择，不是哪份官方文件的规定；它的含义是：影线合计吞掉的振幅不足三成，当天的方向之争才谈得上一边倒。

位置条件：大阳线长在哪都叫大阳线，形状判定不依赖位置；变的是解读。横盘区下沿出现的第一根大阳线，常是多方宣布接管的开幕；连续上涨后的加速大阳线，则可能是最后的燃料——同样的形状，前者常开始一段行情，后者常结束一段行情。

应对与失效：出现大阳线，且它收在你事先画好的压力区之上、成交量同步放大时，常见的应对是把「多方当日控盘」记为一条事实，再等回踩考虑介入。不要追在实体的顶端——追高的亏损，多发生在把「当天控盘」当成「明天继续涨」的那一秒。失效条件：次日收盘跌回这根大阳线实体的一半以下，控盘判断作废。大阴线镜像同理：它宣告当日空头控盘，跌破大阴线最低价的后续走弱才算确认。

## 光头光脚：连反扑的痕迹都没有

剧本：光头光脚（上下影线都短到可以忽略的 K 线——开盘即一路单边到收盘）是「一边倒」的极端版：不仅收盘比分悬殊，盘内连一次值得记录的反扑都没发生。买方或卖方从第一笔成交就掌握了全天，对手方全程观望。

数值判据：上下影线各不超过振幅的 5%。开 10.00、收 10.85、高 10.85、低 10.00，两条影线长度都是零，这是教科书插画级的样本。注意它同时满足大阳线的判据（实体占比 100%）——识别器会把两个名字都放进名单：`big-yang` 与 `marubozu`（光头光脚的英文名）。名字不互斥，它们是对同一组数字的不同侧面的描述。

位置条件与应对：与大实体家族相同，位置不改变形状判定，只改变解读。A 股语境里，光头光脚大阳线常见于利好集中兑现的日子，涨停板附近尤其多；「开盘即封死、四价合一」的一字板则是它的极端形态，那种 K 线归第 6 章的十字星家族管。应对句式：出现光头光脚大阳线且当日放量、且次日不回补实体时，常见的应对是顺着控盘方向等待回踩机会；失效条件：次日低开吞掉大半实体，说明所谓全天控盘只是单日情绪。

## 锤子线与上吊线：同一根 K 线的两种身世

现在是全章的核心：位置第一次成为判定的一部分。锤子线与上吊线（hanging man——形状与锤子线完全相同，只因出现在一段上涨之后而换了名字）是同一组几何约束的两个出口。

锤子的剧本：一段下跌之后，某天空头再度发难，价格深砸；但到收盘，价格回到了开盘附近。0.40 元的下影意味着：有人在这一天里以低一档的价格卖出过，也有人在同样的位置把货全部接走，还把价格推了回来。长下影是这场承接战的全程记录——它不保证见底，它只证明「这个价位今天有人愿意要」。

上吊的剧本：同一张图出现在一段上涨之后，读法反过来。上涨途中，盘中突然深砸——高位第一次出现这么急的卖压，即便尾盘接了回来，「有人开始在这个位置大笔出货」本身就是新信息。承接方赢下了当天，但对手已经亮过相了。

数值判据：下影线不低于实体的两倍，上影线不超过实体，实体占比高于 5%（更薄的近十字 K 线是另一套剧本，归下一章的十字星家族）。用本章图表里的样本算一遍：开 10.00、高 10.18、低 9.60、收 10.15。实体 0.15，下影 0.40（开盘 10.00 减最低 9.60），上影 0.03，振幅 0.58。检验：下影 0.40 ≥ 2×0.15=0.30，成立；上影 0.03 ≤ 0.15，成立；实体占比 26%，高于 5%。判定通过，接下来轮到位置发言。

位置条件：形态之前五根 K 线（默认回看窗）的收盘累计跌幅不低于 5%，才算「出现在一段下跌之后」，判锤子线；累计涨幅不低于 5%，判上吊线；涨跌都在 5% 以内，不命名——位置不明就不赌方向。看下面两张图：下跌段与上涨段各 34 根，第 31 根植入的是同一组数字（开 10.00、高 10.18、低 9.60、收 10.15），识别器在左图叫它锤子线、右图叫它上吊线。

应对与失效：锤子线出现在一段不少于 5% 的下跌之后、且次日收盘没有跌破锤子线的最低价时，常见的应对是把「下方出现承接」记为一条线索，等确认信号再动手，不要当天就买。开章那根 1.33 倍的假锤子，连线索都算不上。失效条件：次日收盘跌破锤子线最低价，承接判断作废。上吊线出现在一段不少于 5% 的上涨之后、且次日收盘跌进上吊线实体之内时，常见的应对是收紧止盈、不再加仓；失效条件：次日放量收阳创出新高，警示作废。

## 射击之星与倒锤子：向上那一刺的两种读法

射击之星的剧本：一段上涨之后，多头向上发起冲锋，盘中创出新高——收盘却缩回开盘附近。上影线是这次冲锋的验尸报告：上方有人挂了大量卖单等着出货，多头冲上去试了一次，全额打了回来。它是一次「实弹测试」：上方的抛压从猜测变成了事实。

倒锤子的剧本：同一形状出现在一段下跌之后：跌了多日，某天多头第一次认真上探，虽然收盘还是缩了回来，但「敢于上探」说明空方已经压不出新低，卖压不再是无限子弹。倒锤子的信息量比射击之星弱——冲锋失败了毕竟还是失败——所以它需要次日收阳确认：第二天收出高于倒锤子实体的阳线，这次上探才算被追认。

数值判据：上影线不低于实体的两倍，下影线不超过实体，实体占比高于 5%。图表样本：开 10.00、高 10.68、低 9.85、收 9.85。实体 0.15，上影 0.68（最高 10.68 减实体上沿——这根是阴线，实体上沿是开盘价 10.00），下影 0，振幅 0.83。检验：上影 0.68 ≥ 0.30，成立；下影 0 ≤ 0.15，成立；实体占比 0.15 ÷ 0.83 ≈ 18%，高于 5%，成立。

位置条件：与锤子一家同构，之前五根累计涨幅不低于 5% 判射击之星，累计跌幅不低于 5% 判倒锤子，横盘不命名。下图两段行情的第 31 根又是同一组数字，识别器在上涨段叫它射击之星、在下跌段叫它倒锤子。

应对与失效：射击之星出现在一段不少于 5% 的上涨之后、且次日收盘收在射击之星实体之下时，常见的应对是把「上方抛压已实测」记入证据链，停止追加、收紧止盈；失效条件：次日放量收阳、收复整条上影，测试结论作废。倒锤子出现在一段不少于 5% 的下跌之后、且次日收阳高于倒锤子实体时，常见的应对是把它当作「卖压衰减」的候选线索，等第三日不创新低再升级为线索；失效条件：次日收阴且跌破倒锤子最低价。

## 渐进实验：把位置写进判定

老规矩，先写测试看它红。本章测试的核心断言就是全章的核心命题——同一组数字，背景换，名字换：

```ts
// tests/single-patterns-wicks.test.ts · 同一形状，名字随背景反转
  it('同一根长下影小实体：下跌背景判锤子，上涨背景判上吊，横盘不命名', () => {
    expect(classifyWicks(HAMMER_SHAPE, ctx('falling'))).toEqual(['hammer'])
    expect(classifyWicks(HAMMER_SHAPE, ctx('rising'))).toEqual(['hanging-man'])
    expect(classifyWicks(HAMMER_SHAPE, FLAT)).toEqual([])
  })
```

端到端再压一遍：样本接在两段手搓背景（等差下跌与等差上涨）后面，背景经 `trendContext` 算出，再喂给识别器。

```ts
// tests/single-patterns-wicks.test.ts · 端到端：同一组数字，背景换名字
  it('端到端：同一组数字接在两段真实背景后面，trendContext 喂给 classifyWicks 后名字互换', () => {
    const afterFall = [...FALLING, HAMMER_SHAPE]
    const afterRise = [...RISING, HAMMER_SHAPE]
    expect(afterFall[8]).toEqual(afterRise[8]) // 同一根K线、同一组数字
    expect(classifyWicks(afterFall[8], trendContext(afterFall, 8))).toEqual(['hammer'])
    expect(classifyWicks(afterRise[8], trendContext(afterRise, 8))).toEqual(['hanging-man'])
  })
```

实现分两个文件。`src/patterns/context.ts` 管位置：回看形态之前的五根，取窗口两端收盘价算涨跌幅，超过 5% 才算有方向。只用形态当天以前的数据——「末端」要等未来走出来才知道，事中能判的只有「出现在一段上涨或下跌之后」，这也是拒绝未来函数的立场。

```ts
// src/patterns/context.ts · 窗口与判向
  const first = candles[index - lookback]
  const last = candles[index - 1]
  for (const end of [first, last]) {
    if (!Number.isFinite(end.close) || !(end.close > 0)) {
      throw new Error(`trendContext：背景窗口两端的收盘价必须是正的有限数字，收到的是 ${end.close}`)
    }
  }
  const change = (last.close - first.close) / first.close
  const position: TrendPosition = change <= -threshold ? 'falling' : change >= threshold ? 'rising' : 'flat'
  return { position, change, bars: lookback }
```

`src/patterns/wicks.ts` 管形状。四条数值判据写成常量，判据与叙述一一对应。

```ts
// src/patterns/wicks.ts · 四条数值判据
/** 实体占全天振幅达到该比例记「大」：一方从开盘压到收盘 */
const BIG_BODY_RATIO = 0.7
/** 上下影各不超过振幅的该比例记「光头光脚」：全天没有像样的反攻 */
const BALD_WICK_RATIO = 0.05
/** 影线达到实体的该倍数才算「长影」 */
const WICK_VS_BODY = 2
/** 实体占比低于该值的近十字K线留给十字星家族（下一章） */
const BODY_FLOOR_RATIO = 0.05
```

判据先喂给三根与位置无关的形状：大阳、大阴、光头光脚——不看背景，只看比分。

```ts
// src/patterns/wicks.ts · 与位置无关的三个形状
  // —— 与位置无关的三个形状 ——
  if (a.direction === 'yang' && a.bodyRatio >= BIG_BODY_RATIO) out.push('big-yang')
  if (a.direction === 'yin' && a.bodyRatio >= BIG_BODY_RATIO) out.push('big-yin')
  if (
    a.direction !== 'doji' &&
    a.upperWickRatio <= BALD_WICK_RATIO &&
    a.lowerWickRatio <= BALD_WICK_RATIO
  ) {
    out.push('marubozu')
  }
```

位置换算的出口只有六行——两个形状对，各自由背景挑名字。

```ts
// src/patterns/wicks.ts · 位置换算的两个形状对
  const hasBody = a.bodyRatio > BODY_FLOOR_RATIO
  const longLower = a.lowerWick >= WICK_VS_BODY * a.body && a.upperWick <= a.body
  const longUpper = a.upperWick >= WICK_VS_BODY * a.body && a.lowerWick <= a.body
  if (hasBody && longLower) {
    if (context.position === 'falling') out.push('hammer')
    else if (context.position === 'rising') out.push('hanging-man')
  }
  if (hasBody && longUpper) {
    if (context.position === 'rising') out.push('shooting-star')
    else if (context.position === 'falling') out.push('inverted-hammer')
  }
```

本章图表的数据由 `export-docs` 脚本追加导出：合成带漂移的趋势行情（每天平均涨或跌 2%），在第 31 根植入构造样本，再用识别器扫全序列产生标记。锤子对的守门条件直接写在脚本里。

```ts
// companion/scripts/export-docs-data.ts · 同一组数字，两种背景（位置换算的教学不变量）
const fallHammer = plantAt(driftSeries(createRng(506), { days: 34, startPrice: 18.4, drift: -0.02, vol: 0.009 }), AT, CH5_HAMMER)
const riseHang = plantAt(driftSeries(createRng(507), { days: 34, startPrice: 5.5, drift: 0.02, vol: 0.009 }), AT, CH5_HAMMER)
const fallInvert = plantAt(driftSeries(createRng(508), { days: 34, startPrice: 18.4, drift: -0.02, vol: 0.009 }), AT, CH5_STAR)
const riseStar = plantAt(driftSeries(createRng(511), { days: 34, startPrice: 5.5, drift: 0.02, vol: 0.009 }), AT, CH5_STAR)

if (!sameNumbers(fallHammer[AT], riseHang[AT])) throw new Error('锤子对两图不是同一组数字：位置换算的前提被破坏')
if (!sameNumbers(fallInvert[AT], riseStar[AT])) throw new Error('长上影对两图不是同一组数字：位置换算的前提被破坏')
```

样本数字本身也守第 2 章的规矩：影线深度全部控制在相对前收盘 ±10% 的涨跌停边界之内——构造样本不能带头违反交易所规则。简化之处照实声明：判据阈值（七成、5%、两倍、回看五根、涨跌 5%）是本课程的操作化选择；不检查教科书常提的「跳空」条件；上吊线与射击之星不限定阴阳颜色。全部差异登记在附录差异清单。

## 小结

- 单根形态的完整判据 = 形状数字 + 位置条件。锤子线与上吊线、倒锤子与射击之星各是同一形状的两个名字，背景涨跌方向决定归属，横盘不命名。
- 数值判据全部来自 `candleAnatomy` 的读数：大实体看实体占比（≥70%），光头光脚看双影（各 ≤5%），长影族看影线与实体的两倍关系（实体占比 >5%），位置看前五根累计涨跌（≥5%）。
- 每条应对都是条件句，且都带失效条件：形态是线索的入口，不是动作的扳机。这些线索到底有多可靠，第 9 章用统计逐一验货。

读完本章，你应该能回答：

1. 开 12.30、高 12.32、低 11.60、收 12.00 的 K 线，为什么连锤子线的候选都算不上？
2. 同一根长下影 K 线，出现在什么样的背景里叫上吊线？上吊线的剧本和锤子线差在哪一句？
3. 光头光脚大阳线的识别结果里为什么有两个名字？
4. 「位置在下跌中段」的锤子线陷阱，本章的操作化规则能挡住哪一部分、挡不住哪一部分？

去向一句话：第 6 章处理实体缩到零的极限——十字星家族，开收同价、只剩影线的那些 K 线，以及四价合一的一字板。
