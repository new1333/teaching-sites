去年春天你在一只 10 元上下的票上赚过一波：8.2 元拿进去，拿到 11.4 元。图上三个山峰你亲眼看着它长出来。11 元附近第一次冲高回落，你没动，那是涨势里正常的回踩；11.4 元那根大阳冲顶，你在 11 元上方加了两成仓，觉得新高只是时间问题；再弹回 10.7 元上不去了，你安慰自己这是回调上车点。等到四月末那根阴线收盘砸穿 9.8 元一线，你才翻出软件里的形态百科对照：头肩顶，教科书图例分毫不差。头肩顶（head and shoulders——中间一峰最高、两侧肩部略低的三峰反转结构，形似一个人的双肩和头）说的正是三段接力：涨势三次冲顶，买方接力一次比一次弱。可认出它的这一天，价格离头顶已经跌了一成半，账上利润跌掉一半。你亏的不是运气，是顺序：先看到结局，才认出结构。答案其实早就写在颈线（neckline——连接两次回撤低点的参考线，收盘跌破它结构才算成立）上，只是你当时不会量。

本章把「认出」提前到右肩成形那天。三件事：讲清三峰结构的剧本与量度目标（measured move——把结构高度从颈线向破位方向投影得出的参考价位，量的是惯性大概能把价格送多远）；把头肩顶、双顶、双底写成一个可复算的函数；顺带讲透缺口（gap——两根 K 线之间没有任何成交的价格真空区）的三种性格。

## 头肩顶：三段情绪的接力

先说清这个形状为什么会长出来。头肩顶不是画在图上的符咒，是三次买卖换手留下的记录，一段一段拆开看。

第一段，左肩。趋势里的正常回撤：创新高，回踩，再上——第 10 章的上行台阶就是这样走的。单看这一段，没有任何理由下车，它本来也不该让人下车。

第二段，头。最后的冲锋：价格再创新高，但常常量能已经跟不上第一波——第 12 章的量价背离刻度当场可用。新高往往是最犹豫的观望者终于忍不住追进去买出来的：燃料是最后一批买盘。

第三段，右肩。乏力：第三次上攻到不了头的高度。前高附近堆着两批卖家——第一批在左肩买的要落袋，第二批在头追进去的要解套——新买盘接不上力，冲锋在半坡熄火。第 14 章的筹码图在这里兑现承诺：头顶下方那座最厚的套牢峰，正是这两批卖家的实体——每次反弹到峰腰，解套盘就涌出来；形态的每一步，都踩在筹码的地图上。

第四段才是判据。颈线：两次回撤低点的连线。收盘跌破它，三峰才从「一段涨势的抖动」升格为「反转结构」。**结构成立的判据只有一条：收盘跌破颈线**，盘中影线刺破不算——这与第 10 章趋势线、第 13 章破位的口径一字不差。

## 双顶与双底：同一个价位两次证明有人守

头肩顶还有一个退化版：头没长出来。双顶（double top——两次冲击同一价位失败形成的 M 形顶部）的机制回看第 13 章就够：第一次上攻在某个价位撞上解套与获利的卖压，回落；第二次再来，同一批人还守在那里挂单。**同一个价位，第二次证明有人守**，买方两次都啃不动，就换了主张。双底（double bottom——镜像的 W 形底部）是同一件事倒过来：两次砸坑都砸不穿，证明下方有人接。三峰里中间那座高出来，是头肩顶；高不出来，是双顶。

「同一价位」怎么判？不能靠眼睛。实验场的口径：两峰枢轴价的差不超过容差算同水平，图上显式取 0.25 元（默认取全序列平均振幅的一半，与第 13 章聚类容差同款）。中间谷还要拉开深度——浅折返只是同一波上涨的歇脚，不配叫双顶。

跟着图核数。峰 1 第 8 根高 10.57 元，峰 2 第 23 根高 10.60 元，差 0.03 元，同水平成立。颈线取中间谷低点 9.26 元（第 15 根）。顶价取两峰均值 10.585 元，结构高度 10.585 − 9.26 = 1.33 元。第 28 根收盘 9.16 元首次跌破颈线，量度目标 = 9.26 − 1.33 = 7.93 元，末根收 8.01 元。

双顶的量度推演与头肩顶同一个算式：高度从颈线投影。方向反过来就是双底——两次探底不穿、收盘涨过中间峰，目标从颈线向上投影。它的条件句也镜像：若你观察的标的走完 W 形、收盘涨过中间峰，常见的应对是把中间峰上方设为参照、以跌回颈线为失效；收盘跌回谷底之下，结构作废。

双底别只停留在镜像想象里，看一张实物。下图 32 根 K 线，四个标记点出结构的关键角色：谷 1、颈线峰、谷 2、突破日。

## 缺口：真空区的三种性格

反转结构讲完了「价格在哪里掉头」，还剩一种 A 股高频现象要单独讲。缺口的成因在第 2 章埋过伏笔：开盘价由集合竞价定。隔夜出了大消息，第二天所有报价整体抬高或压低，开盘价直接落在远离昨收的位置——昨天的最高价与今天的最低价之间出现一段没有成交过的真空。涨跌停制度还会把真空放大：利好一字板，就是封死在涨停边界上的缺口（第 6 章的一字线）。

同一个形状，三种性格，分诊只问两件事：多快回补、量放多大。

普通缺口。震荡区里的零星跳空：横盘两三个月的票，某晚隔夜外盘涨了一些，或传了一条不痛不痒的消息，次日高开一个点留下小真空。没有接力资金，两三天内日内波动就把真空走完。它不预测方向，也基本不含信息。

突破缺口。脱离成本区的跳空：停牌重组复牌、业绩预增公告、行业政策落地——集合竞价直接开在几个月横盘区的上沿之外，且放量（想买的排队、想卖的惜售），此后久久不回补。市场用真金白银投票：这个区域上方重新定价。老话「缺口不补，强势依旧」说的就是它。

衰竭缺口。急涨末端的最后一跳：题材股连板（连续多个交易日涨停板）后的高开跳空——比如第五个涨停前那天的跳空，封单越来越薄、量能放不动了。想卖的在等更高的价，想买的不敢再追，最后一跳是燃料烧尽前的火苗。随后某天巨量把封死的涨停打开（「开板」），价格跌回缺口、反转向下。

<KLineChart :candles="gaps.candles" :markers="gaps.markers" title="缺口三性格：普通、突破、衰竭" />

核数。普通缺口 03-16：昨高 10.25、今低 10.35，真空 10.25 到 10.35；三天后 03-19 最低 10.05，走完真空。突破缺口 03-30：昨高 10.42、今低 10.70，当日量 30 万股，是前五日均量 9.2 万股的 3.3 倍，此后最低价再没回到 10.70 之下。衰竭缺口 04-15：昨高 12.40、今低 12.65；04-17 最低 12.20 回补，随后一路收低到 04-22 的 11.40。标记由导出段的扫描器逐对核对后落点，缺口识别不进实验场模块（不属于本章 milestone），这点照实声明。

写成条件句：若你持仓且急涨末端出现向上跳空、量能不再放大，常见的应对是把止损收到缺口下沿；失效条件是缺口三天不回补且量能持续放大，按突破缺口对待，止损位相应上移。若横盘区上沿出现放量跳空、三天不回补，常见的应对是不追第一根、等回踩缺口上沿不破再参与；收盘跌回缺口之内即失效。

// src/levels/structures.ts · Structure 类型
/** 一个反转结构：枢轴下标、颈线、破位日与量度目标，件件可回图核对 */
export type Structure = {
  id: StructureId
  /** 方向：头肩顶与双顶看跌（bear），双底看涨（bull） */
  direction: 'bear' | 'bull'
  /** 构成结构的枢轴下标（时间旧→新）：头肩顶 [左肩,左谷,头,右谷,右肩]，双顶 [峰,谷,峰]，双底 [谷,峰,谷] */
  indices: number[]
  /** 颈线价：头肩顶取两谷枢轴价的均值，双顶/双底取中间谷/峰的枢轴价——简化为水平线 */
  neckline: number
  /** 破位 K 线下标：右肩/第二峰之后第一根收盘越过颈线的 K 线，结构在这天成立（盘中影线不算） */
  breakIndex: number
  /** 量度目标：结构高度（头/顶价到颈线）从颈线向破位方向投影的价位——参考区，不是承诺 */
  target: number
}
```

// src/levels/structures.ts · detectStructures 全貌
/** 反转结构检测：先让 pivots 把行情切成峰谷交替的拐角序列，再在拐角序列上找两类反转候选——
 *  「高、低、高、低、高」五连是头肩顶候选（头要高出一截、两肩与两谷各自同水平）；
 *  「高、低、高」/「低、高、低」三连是双顶/双底候选（两端同水平、中间要拉开深度）。
 *  骨架只是候选：还要右肩/第二峰之后有一根 K 线收盘越过颈线，结构才成立——
 *  这与第 10 章趋势线、第 13 章破位的收盘口径一字不差，盘中影线刺破不算数。 */
export function detectStructures(candles: readonly Candle[], opts: StructuresOpts = {}): Structure[] {
  if (!Array.isArray(candles) || candles.length === 0) {
    throw new Error('detectStructures：candles 不能为空')
  }
  const k = opts.k ?? DEFAULT_PIVOT_WINDOW
  const tol = opts.tol ?? avgRange(candles) / 2
  if (!(tol > 0) || !Number.isFinite(tol)) {
    throw new Error(`detectStructures：tol 必须是正数（同水平容差），收到的是 ${tol}`)
  }
  for (let i = 0; i < candles.length; i++) {
    const c = candles[i]
    if (!Number.isFinite(c.high) || !Number.isFinite(c.low) || !Number.isFinite(c.close)) {
      throw new Error(`detectStructures：第 ${i} 根的高低收盘价必须是有限数字，收到的是 ${c.high}/${c.low}/${c.close}`)
    }
  }
  const ps = pivots(candles, k)
  if (ps.length === 0) return [] // 拐角都没有，结构无从谈起：不猜

  /** 破线扫描：from 起第一根收盘越过 neckline 的 K 线（向下 <，向上 >）；找不到返回 -1 */
  const breakAfter = (from: number, neckline: number, up: boolean): number => {
    for (let i = from; i < candles.length; i++) {
      if (up ? candles[i].close > neckline : candles[i].close < neckline) return i
    }
    return -1
  }

  const out: Structure[] = []

  // 双顶 / 双底：连续三个枢轴两端同侧（pivots 峰谷交替，三连必是 X、Y、X）
  for (let w = 0; w + 3 <= ps.length; w++) {
    const [a, mid, b] = [ps[w], ps[w + 1], ps[w + 2]]
    if (Math.abs(a.price - b.price) > tol) continue // 两端不同水平：LH/HL 是台阶，不是双顶/双底
    if (a.side === 'high') {
      // 双顶：中间谷要拉开深度——浅折返只是同一波上涨里的歇脚
      if (Math.min(a.price, b.price) - mid.price < tol) continue
      const neckline = mid.price
      const breakIndex = breakAfter(b.index + 1, neckline, false)
      if (breakIndex < 0) continue
      const top = (a.price + b.price) / 2
      out.push({
        id: 'double-top',
        direction: 'bear',
        indices: [a.index, mid.index, b.index],
        neckline,
        breakIndex,
        target: 2 * neckline - top,
      })
    } else {
      // 双底：中间峰要拉开高度
      if (mid.price - Math.max(a.price, b.price) < tol) continue
      const neckline = mid.price
      const breakIndex = breakAfter(b.index + 1, neckline, true)
      if (breakIndex < 0) continue
      const bottom = (a.price + b.price) / 2
      out.push({
        id: 'double-bottom',
        direction: 'bull',
        indices: [a.index, mid.index, b.index],
        neckline,
        breakIndex,
        target: 2 * neckline - bottom,
      })
    }
  }

  // 头肩顶：连续五个枢轴「高、低、高、低、高」，头居中
  for (let w = 0; w + 5 <= ps.length; w++) {
    const [ls, a, head, b, rs] = [ps[w], ps[w + 1], ps[w + 2], ps[w + 3], ps[w + 4]]
    if (ls.side !== 'high') continue
    if (Math.abs(ls.price - rs.price) > tol) continue // 两肩不同水平：三峰错落是别的形状
    if (head.price < Math.max(ls.price, rs.price) + tol) continue // 头没高出一截：贴着肩的峰是平台
    if (Math.abs(a.price - b.price) > tol) continue // 两谷不同水平：水平颈线（简化）的前提
    const neckline = (a.price + b.price) / 2
    if (Math.min(ls.price, rs.price) - neckline < tol) continue // 肩与颈线要拉开：贴着肩的谷构不成头肩
    const breakIndex = breakAfter(rs.index + 1, neckline, false)
    if (breakIndex < 0) continue
    out.push({
      id: 'head-and-shoulders',
      direction: 'bear',
      indices: [ls.index, a.index, head.index, b.index, rs.index],
      neckline,
      breakIndex,
      target: 2 * neckline - head.price,
    })
  }

  // 按结构起点从旧到新返回
  return out.sort((m, n) => m.indices[0] - n.indices[0] || m.breakIndex - n.breakIndex)
}
```

</details>

读一遍三个承重点。其一，骨架扫描就是在峰谷交替的枢轴序列上滑窗口：三连管双顶双底，五连管头肩，判断条件全部是「同水平容差 + 拉开深度」的数值判据，没有一处靠形状感觉。其二，骨架只是候选——`breakAfter` 只认收盘，向 下破用 `<`、向上破用 `>`，找不到破线日整件候选直接丢弃。这正是「右肩成形不等于结构成立」的机械表达。其三，量度目标统一写成 `2 × 颈线 − 顶价`，头肩顶用头顶价、双顶用两峰均价，同一算式。

图一图二的数据照旧出自 export-docs 脚本第 15 章导出段，守门内置：头肩段必须恰好检出一个头肩顶、头高减颈线至少 1.2 元、末根收盘距量度目标不超过 0.5 元；双顶段两峰价差必须落在容差内、破位读数自相矛盾即失败；缺口段必须恰好扫出三处向上缺口，普通缺口第 15 根内回补、突破缺口全程不回补且量能不足前五日均量 2.5 倍即失败。任一失手，整段导出失败。

简化之处照实声明并登记附录差异清单：颈线简化为两谷均值的水平线（真实头肩的颈线可以倾斜）；头肩底（倒头肩）未实现；同水平容差统一用 tol（默认平均振幅一半）为课程操作化选择；识别器不检查量能（教科书常要求右肩缩量、破颈线放量确认，第 12 章刻度可另行核对——缩量破颈线要多一分假跌破的警惕）；量度目标为参考口径非承诺；缺口取「普通、突破、衰竭」三种的教学分类，经典四分类里的持续（逃逸）缺口不单列；缺口识别是教学剧本加脚本内扫描器，不进 src；三图为固定种子合成行情。

## 小结

- 头肩顶是三段情绪的接力：左肩是正常回撤、头是最后的冲锋、右肩是乏力；颈线（两谷均值）是结构成立的判据，收盘跌破才算，影线刺破不算。
- 量度目标 = 结构高度从颈线向破位方向投影；右肩成形那天就已画得出、量得出——这就是把「认出」提前的全部含义。
- 双顶双底是同一个价位的两次证明，头肩顶是它的三峰版；「同水平」由容差判出，不靠眼睛。
- 缺口分普通、突破、衰竭三种性格，分诊只问两件事：多快回补、量放多大；三种各有各的应对与失效条件。
- 全部判据进了实验场：`detectStructures` 复用第 13 章的 `pivots`，只增不改。
