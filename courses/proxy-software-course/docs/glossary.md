# 术语表

本页汇总全书出现的全部术语，来自课程事实源 `bible.json`，不做额外补充或删减。

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 正向代理 | forward proxy | 代表客户端连接目标服务器的中间程序，目标服务器直接看到的是代理的连接。 |
| 反向代理 | reverse proxy | 代表服务端接收客户端连接的中间程序，客户端通常把它当成目标站点。 |
| 系统代理 | system proxy | 操作系统提供给愿意遵守该设置的应用的代理地址，不会自动截获所有流量。 |
| TUN | — | 向用户态程序交付 IP 包的虚拟网络接口，可承接不懂 HTTP 或 SOCKS 的应用流量。 |
| 数据面 | data plane | 逐条处理连接和字节的路径：接入、判断、拨号、转发。 |
| 控制面 | control plane | 管理配置、规则、节点、健康状态和界面的路径。 |
| absolute-form | — | HTTP 代理请求行携带完整 URL 的目标形式，例如 GET http://host/path HTTP/1.1。 |
| origin-form | — | 发给源站的 HTTP 请求目标形式，只携带路径与查询字符串。 |
| CONNECT 隧道 | — | HTTP 客户端请求代理连接指定 host:port，成功后双方把该 TCP 连接当成不解释内容的字节隧道。 |
| TLS 端到端 | — | TLS 会话建立在客户端与目标服务之间，普通隧道代理只搬运密文，不持有解密密钥。 |
| SOCKS5 | — | RFC 1928 定义的通用代理协议，在 TCP 连接上协商方法并提交目标地址与命令。 |
| 方法协商 | method negotiation | SOCKS5 客户端先列出认证方法，服务端选择一种双方都支持的方法。 |
| 地址类型 | ATYP | SOCKS5 地址帧用来区分 IPv4、域名和 IPv6 的一个字节。 |
| 字节流 | byte stream | TCP 交付有序字节，但不保留发送端每次 write 的消息边界。 |
| TCP 分片 | — | 一段应用协议数据可能分多次到达；接收端必须按长度或分隔符累计到完整字段。 |
| 背压 | backpressure | 写入方跟不上时暂停读取，避免待发送数据在内存里无界增长。 |
| 半关闭 | half-close | TCP 的一个方向已经发送 FIN，另一个方向仍可继续传输。 |
| 连接元数据 | connection metadata | 路由决策可使用的目标域名、解析后 IP、端口和入口等信息。 |
| 首条命中 | first match | 规则从上到下判断，第一条满足条件的规则立即成为最终决策。 |
| 域名标签边界 | — | 域名中点号分隔的层级边界；example.com 可匹配 a.example.com，但不应匹配 evil-example.com。 |
| CIDR | — | 用网络地址和前缀长度表示一段连续 IP 空间的记法，例如 10.0.0.0/8。 |
| DNS 解析位置 | — | 域名究竟在本地代理、上游代理还是目标侧被换成 IP；它决定谁能看到查询以及哪些 IP 规则可用。 |
| preserve-domain | — | 先保留域名做规则判断；直连时本地解析，经上游代理时把域名交给上游。 |
| resolve-first | — | 先把域名解析成 IP，再让域名和 IP 规则共同参与判断。 |
| 出站适配器 | outbound adapter | 把统一的目标地址转换为某种拨号行为，例如直连、拒绝或连接 SOCKS5 上游。 |
| 代理链 | proxy chain | 本地代理不直接连接目标，而是把连接请求交给另一台上游代理。 |
| 严格配置校验 | — | 监听前验证配置的形状、取值和交叉引用，错误时明确失败而不静默猜测。 |
| MATCH 兜底 | — | 规则列表末尾无条件命中的最后一条，保证每个连接都有明确决策。 |
| 依赖注入 | dependency injection | 把 DNS 解析器、拨号器和事件接收器作为参数传入，使网络副作用可替换、可测试。 |
| 结构化事件 | structured event | 带类型、消息和字段的运行记录，便于测试与排障，而不是拼接无法查询的日志句子。 |
| 优雅关闭 | graceful shutdown | 停止接受新连接、清理现有资源，再退出进程。 |
| 威胁模型 | threat model | 明确要保护的资产、可能的攻击者、入口和可接受风险。 |
| 开放代理 | open proxy | 没有可信访问边界、任何人都能借其连接任意目标的代理服务。 |
| 最小权限 | least privilege | 只开放完成任务所需的监听范围、目标范围、命令和权限。 |
