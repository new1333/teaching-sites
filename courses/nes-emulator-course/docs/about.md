# 关于本课程

用 TypeScript 从零写一台 NES:NES 模拟器原理与实现 —— 共 12 章(10 个动手章,全部完成)。

课程由一句主题生成:「使用 TypeScript 从零实现 NES 模拟器;要求能实际解析并运行 ROM,产出的代码完整可运行」。全书围绕一条主线演进一个伴生实验场(TypeScript + vitest):从解析 iNES 卡带起步,经 6502 指令集、总线与 PPU、背景与精灵渲染、帧时序,最终组装成能加载真实 .nes 文件、可在浏览器中游玩的整机。

章节目录:

1. 三块芯片的合奏:NES 硬件全景与时钟同步
2. iNES 格式:拆开一张卡带
3. 6502 最小核心:寄存器、复位与取指循环
4. 寻址模式:操作数从哪里来
5. 指令集与标志位:补全官方 151 条
6. PPU 寄存器与地址镜像
7. 背景渲染:8 个点画一块瓦片
8. 精灵、OAM DMA 与 sprite 0 hit
9. 帧时序:NMI 与主循环
10. 手柄:一次移一位的串行输入
11. 整机组装:从 .nes 字节到第一帧画面
12. 精度阶梯:从「能跑」到「像素级正确」

课程不追求复刻任何现有模拟器的代码,只教核心原理;所有正确性由实验场的单元测试与社区公开测试卡带共同背书。
