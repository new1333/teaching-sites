# 术语表

全书十五个核心术语，一句话大白话定义。首章未讲透的，翻到对应章节再看一遍。

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 模拟器 | emulator | 用软件扮演一整台机器，让为那台机器写的程序以为自己在真机上运行。 |
| 字节 | byte | 8 个二进制位打包成的一格数据，能表示 0~255，是 8 位机世界的基本集装箱。 |
| 十六进制 | hexadecimal | 把每 4 个二进制位缩写成 1 个字符（0-9、A-F）的速记法，0xFF 就是二进制 11111111。 |
| 位运算 | bitwise operation | 直接对二进制每一位做的运算：与、或、异或、左移、右移，硬件上比加减法还便宜。 |
| 补码 | two's complement | 8 位世界里表示负数的约定：255 代表 -1，-128~127 首尾相接成一个环。 |
| 寄存器 | register | CPU 内部屈指可数的几个超高速小格子，数据必须先搬进来才能参与运算。 |
| 标志位 | flag | CPU 做完一次运算顺手留下的便签：结果是零吗？是负吗？进位了吗？供下一条指令查阅。 |
| 寻址模式 | addressing mode | 「操作数从哪来」的 13 种约定：数据在指令里、在内存某格、在某格附近……同一个动作的不同说法。 |
| 总线 | bus | 全机共享的地址加数据干道：CPU 报门牌号，对应地址上的设备负责应答。 |
| 内存映射 | memory map | 把 64KB 门牌号分段出租：$0000 段是 RAM、$2000 段通向 PPU——访问地址就等于访问设备。 |
| 中断 | interrupt | 硬件的电话铃：CPU 暂停手头工作、按向量表门牌号找到处理程序、办完回来原地继续。 |
| 垂直消隐 | VBlank | 一帧画面扫完后电子束回到左上角前的歇息窗口，是修改画面数据的唯一安全期。 |
| 图块 | tile | 8×8 像素的小方格图案，NES 整个画面由几百块图块像马赛克拼贴一样拼成。 |
| 精灵 | sprite | 不受背景网格约束、可逐帧自由摆位的活动图层（角色、子弹），登记在 OAM 表里。 |
| 采样 | sampling | 把连续声波每秒量很多次、把每次振幅记成一个数字；每秒量的次数就是采样率。 |
