# PPU / APU 寄存器速查表

CPU 眼里只有门牌号——这张表是两个「外设窗口」的说明书。

## PPU：$2000-$2007（每 8 个门牌重复一次）

| 门牌 | 名字 | 读/写 | 语义 |
|---|---|---|---|
| $2000 | PPUCTRL | 写 | bit0-1 nametable 基址 · bit2 自增步长（0=+1 / 1=+32）· bit4 背景图案表（0=$0000 / 1=$1000）· bit5 精灵 8x16 · bit6/7 精灵表 / NMI 使能 |
| $2001 | PPUMASK | 写 | bit3 显示背景 · bit4 显示精灵 · bit1/2 裁左右 8 列 · 灰度等 |
| $2002 | PPUSTATUS | 读 | bit7 VBlank · bit6 sprite 0 hit（bit5 精灵溢出本课程未实现）；**读一次即清 VBlank**，并复位 $2005/$2006 两步写入节奏 |
| $2003 | OAMADDR | 写 | OAM 指针 |
| $2004 | OAMDATA | 读写 | 写一格 OAM 且指针顺移；读一格但**不**推进指针（真机行为） |
| $2005 | PPUSCROLL | 写×2 | 滚动 X / Y（两步） |
| $2006 | PPUADDR | 写×2 | 档案室指针：先高 6 位、后低 8 位 |
| $2007 | PPUDATA | 读写 | 按指针读写，随后按步长自增；调色板区 $3F00-$3F1F 直达 |

内存分区：$0000-$1FFF CHR 图案（卡带只读）· $2000-$3EFF nametable（四块逻辑折 2KB 物理，方向由卡带 mirroring 定）· $3F00-$3F1F 调色板（$3F10/$14/$18/$1C 是 $3F00/$04/$08/$0C 的背景色分身）。

时序要点：一帧 262 线 × 341 拍 = 89342 PPU 周期；241 线进 VBlank（可拉 NMI），261 线清 VBlank 与 sprite 0（240 是收尾空行）。

## APU：$4000-$4017

| 门牌 | 通道 | 布局 |
|---|---|---|
| $4000-$4003 | pulse1 | $4000: 占空比(7-6) · halt(5) · 恒定音量(4) · 音量/分频(3-0)；$4001: sweep 使能(7) · 周期(6-4) · 方向(3) · 步长(2-0)；$4002/$4003: 定时器低/高 3 位 + 长度档 |
| $4004-$4007 | pulse2 | 同上 +4 |
| $4008-$400B | triangle | $4008: control(7) · 线性计数器重载(6-0)；$400A/$400B: 定时器 + 长度档（无音量旋钮） |
| $400C-$400F | noise | $400C 同 $4000 布局；$400E: 模式(7) · 周期档(3-0)；$400F: 长度档 |
| $4015 | 状态/开关 | 写：通道启用位；读：各通道长度未耗尽位 |
| $4017 | 帧序列器 | 模式与 IRQ（本课程固定四步模式） |

帧序列器（四步模式，每帧 4 个 quarter、2 个 half 节拍）：quarter 每 7457 CPU 周期（包络/线性计数器），half 每 14914（长度与 sweep）。采样输出约每 40 CPU 周期一个样本（≈44.7kHz）。

噪声周期表（CPU 周期/步）：

`4 8 16 32 64 96 128 160 202 254 380 508 762 1016 2034 4068`

长度档位表（写 $4003/$400B/$400F 高 5 位索引，half 节拍数）：

`10 254 20 2 40 4 80 6 160 8 60 10 14 12 26 14 / 20 16 40 18 80 20 160 22 60 24 14 26 30 28 20 30`

四种占空比序列（8 步，1 处出声；第 11 章有讲解）：

```text
12.5%：0 1 0 0 0 0 0 0
25%  ：0 1 0 0 0 0 1 0
50%  ：0 1 1 1 1 1 1 0
25%⁻ ：1 0 0 0 0 0 0 1   （反相）
```

## 手柄：$4016

写 1 再写 0（strobe）锁存 8 键快照；此后连读 8 次、每次一位，顺序 A、B、Select、Start、上、下、左、右；移空后恒读 1。

## 中断向量表（卡带 PRG 末尾）

| 门牌 | 用途 |
|---|---|
| $FFFA/$FFFB | NMI 处理程序入口（VBlank 拉铃时 CPU 跳这里） |
| $FFFC/$FFFD | 复位向量（开机第一跳） |
| $FFFE/$FFFF | IRQ/BRK 向量 |

## 本课程的简化与未实现（与真机的差异清单）

凡正文声明「真机如此」的行为，本课程都对照过权威文档；以下是**明确声明过的简化**与**未实现**项，拿着正文去对真机资料时，差异都收在这里：

**简化（行为近似，教学够用）**

- 开放总线读恒 0（真机保留最后一次总线读写的残留字节；第 3 章）
- sprite 0 hit 边界两列一律不触发（真机仅 x=255 恒不触发，x=0-7 在未开左列裁剪时可命中；第 9 章）
- 混音为四路线性求和 /60（真机是带各通道权重的非线性公式；第 12 章）
- 渲染为进 VBlank 时整帧离线完成（真机逐线实时取图，有取数竞争；第 10 章）
- 一帧固定 89342 拍（真机奇数帧预取线短半拍，均值 89341.5；第 10 章）
- 包络衰到 0 即停（halt 位挂住长度倒数，但包络不循环重启）

**未实现（进阶去向）**

- DMC 采样通道（第五声道，放预录采样）
- mapper 1 以上（大容量卡带换页：MMC1/MMC3 等）
- 逐拍级精确时序（奇偶帧半拍差、DMA 停摆周期、精灵取数竞争）
- $2002 bit5 精灵溢出（真机此位常有误报，主流游戏不依赖）
- 行级滚动分割（真机靠 sprite 0 hit 在一帧内切两次滚动值，让状态栏钉在屏顶；本课程实现的是整帧单一滚动——试机台里 SMB 的状态栏会随世界一起滚动）
