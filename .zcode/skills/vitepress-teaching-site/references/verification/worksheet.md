# worksheet

适合数值、统计、费率、演算与决策课。验证物是确定 fixture、唯一答案、纯计算实现和正文数据导出。

## 循环

1. 写本章 fixture 与期望答案，先让核对命令因求解能力缺失而失败。
2. 实现纯计算，使答案核对转绿。
3. 运行 export-docs，把正文承重数字与图表数据生成到 `docs/assets/data/`。
4. 固定种子、排序和舍入约定，连续导出两次并比对。
5. 正文从导出产物取数；评审抽样手算，防止实现与期望答案同错。

## 约束

- 每道题输入确定、答案唯一；需要区间或多解时把判定规则写进 fixture。
- 舍入、单位、日期边界和缺失值规则集中在 bible verification conventions。
- 正文不手编承重数字，不把“脚本通过”当成事实来源。
- 时间敏感数字同时记录 `as_of` 与权威来源。

完成条件：答案核对、导出守门和抽样复算均通过，正文数字与导出文件一致。
