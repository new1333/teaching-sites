# code-lab

适合库、框架、解析器、CLI、配置或 DOM 行为。验证物是本章新增的行为测试与使其通过的最小实现。

## 变体

| 变体 | 典型门槛 |
|---|---|
| library | typecheck + unit tests |
| cli-golden | build + 固定输入的 golden 输出比对 |
| config-validate | 对应工具的 validate/dry-run |
| dom-test | build + DOM 行为断言 |

outline 的 `companion.commands` 写实际命令，不把表里的示例当成固定工具链。

## 循环

1. 快照 `companion/src` 与将触及的配置。
2. 新增本章测试文件；断言 milestone 的外部行为。
3. 运行本章测试并确认它因“能力尚未实现”而失败，不是语法、路径或环境错误。
4. 演进实现，使本章测试转绿。
5. 运行全部旧测试与静态门槛，确认公共行为未回退。
6. 正文引用终态代码；标注真实相对路径与符号。

## 约束

- 每章新增自己的测试；旧测试保持只读。
- 测试从课程契约设计，不复制上游项目测试。
- 断言行为；只有被 bible API contract 明确承诺的内部面才可直接断言。
- 网络、时间、随机性和本机路径应被固定或隔离。
- 承重代码块与 companion 当前终态一致；省略只用于明确标注的教学拼版。

完成条件：本章测试先红后绿、全量门槛通过、正文引用闸门通过。
