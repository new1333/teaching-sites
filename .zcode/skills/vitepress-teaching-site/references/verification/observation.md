# observation

适合工具操作、环境配置、现场现象与流程训练。验证物是一组可判定任务。

每条任务使用：

```md
- [ ] {读者动作}；应看到 {具体结果}
```

结果应能截图、抄值或逐项对照，例如第二行文本、状态码、界面标签、文件变化。环境要求在任务前声明。

## 循环

1. 先写任务和唯一可对照结果。
2. 在可用环境亲自执行；无法执行时引用可复现证据并明确限制。
3. 让另一条路径或错误输入出现不同结果，确认判据能区分成功与失败。
4. 正文安排“先猜后做”，随后给排错分支。
5. 运行 observation lint。

依赖真实账号、硬件或密钥时，不伪造成功输出；写清环境、可验证边界与替代观察面。

完成条件：每条任务都含动作和具体结果，成功/失败可区分，环境限制可见。
