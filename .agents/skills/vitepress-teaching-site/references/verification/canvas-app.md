# canvas-app

适合画面、音频、动画、交互或数据可视化。验证物是可构建页面和由 companion 真实代码现场产出的资产。

## 循环

1. 建立能断言本章行为的测试或最小探针，并确认预期失败。
2. 演进页面/渲染代码，运行 typecheck、test 与 build。
3. 运行资产导出脚本两次；固定种子、排序与元数据后，输出逐字节一致。
4. 课程组件 import companion 或导出数据的产物，不平行手抄第二套算法。
5. 正文直接嵌入读者可看到、听到或操作的结果，并给复现命令。

## 资产

- 图片和数据放 `docs/assets/`，交给 Vite 打包。
- raw HTML 媒体通过 `<script setup>` import 后绑定 URL。
- 资产记录再生成命令；正文数字以导出结果为事实源。
- 响应式容器使用课程版心；重依赖按需或动态导入。

测试输出只证明机械正确。milestone 本来能被感知时，页面、图像、声音或交互结果才是读者信号。

完成条件：typecheck/test/build 全绿，资产双跑一致，单课与聚合构建均能加载资产。
