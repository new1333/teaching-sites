# none

`none` 是纯原理或复盘章的诚实形态，不是跳过质量门。

写正文前先列本章的**证据包**：

- 要解释的结论；
- 支撑结论的权威来源、反例、推导或已通过的前章验证物；
- 读者能完成的迁移题或口头复述判据。

正文验证槽改为“解释/推导检查”：读者先预测或复述，再用反例、结构图、演算或答案锚点核对。评审逐条检查 acceptance；没有 companion 增量。

`profile.verification: none` 必须在大纲确认时明确说明课程终点只到“理解/解释”。如果能建立 worksheet、observation 或 probe，就使用更强的模式。

完成条件：证据包足以支撑断言，正文 acceptance 全部可判定，评审无阻断项。
