向量：图形世界的语言 ​

第 3 章收工时，三角形已经会转、颜色已经会呼吸。接下来自然想把这套动画搬进小游戏：屏幕一角停着一艘飞船，点一下目标点，它就该朝那边飞过去。

第一版代码出奇地顺利。「从我指向目标」的方向用减法一步就算出来了，每帧沿它挪一点，飞船真的动了。可盯着看十秒就发现不对劲：出发时风驰电掣，离目标越远飞得越快；快到时又猛地慢下来，最后几步简直是爬行——整段航程忽快忽慢，像一辆油门时踩时松的车。第 3 章的缓动是刻意给速度曲线整形；这里的忽快忽慢没有任何设计，是事故。

问题不在减法——减出来的方向完全正确；问题在它的长度。减出来的向量，长度恰好等于到目标的距离：离得远它就长，离得近它就短。把一个混着距离的方向直接当速度用，速度当然跟着距离塌缩。修复只要一步：先把方向归一化——把长度缩成 1、只留朝向——再乘固定步长，飞船每帧就走固定的一步。

这一章把这笔账从头算清。向量是图形世界的通用语——位置、朝向、速度、光的来向、面的朝向，后面凡是「有方向的数量」都用它装。你不需要学过线性代数，本章从零开始：加减、数乘、长度、点积、叉积、归一化，每个运算都配一段纸笔可复算的数值演算。主教材只有一组数：3、4、5。

先踩一遍坑：速度里混着距离 ​

把飞船的更新写成代码（sub、add、scale 是本章要造进实验场的函数，先混个脸熟），痛点版长这样：

js
// 用法示例：痛点版——方向当速度，速度里混着距离
const dir = sub(target, ship.pos)        // 从飞船指向目标，长度 = 到目标的距离
ship.pos = add(ship.pos, scale(dir, dt)) // 每帧步长全看离多远：忽快忽慢

dt 是第 3 章的增量时间——每帧实际流逝的秒数，帧率不匀也等速的那味药；这段代码住在渲染循环的「更新」一步里。对着 3-4-5 的账本把 bug 看穿：

text
跟着算一遍：飞船在 (1,1,0)，目标在 (4,5,0)
方向 = 目标 − 飞船 = [4−1, 5−1, 0−0] = [3,4,0]
长度 = √(3² + 4² + 0²) = √25 = 5     ← 到目标的距离就藏在方向里
痛点版每帧走 dir × dt：步长 = 距离 × dt
距离 5 时每秒挪 5，距离 0.1 时每秒挪 0.1——速度随距离塌缩

方向向量里混着距离。减法一步给出的东西，方向与长度缠在一起；要方向不要距离，就得把长度剥掉。修复版先按下不表，等工具凑齐回来收账。

向量：带箭头的走法说明 ​

先回答「为什么存在」。图形学里的量分两种：纯数量，一个数就够，比如亮度 0.8；带方向的量，比如位置、速度、光从哪来、表面朝哪边——后者占绝对多数。装下「方向 + 长度」最省的容器是三个数：x、y、z 各管一根轴。这就是向量（vector）——打个比方：一张带箭头的走法说明，箭头指朝哪走，长度记走几步。

text
 y
 4 │            ● 目标 (3,4)
 3 │         ↗
 2 │      ↗     方向 [3,4,0]：朝右上走，
 1 │   ↗        长度 5（勾股：√(3²+4²)）
 0 └────┴────┴──→ x
        3    4

轴的朝向沿用第 2 章裁剪坐标系的家规：x 朝右、y 朝上、z 朝屏幕外（朝你）——这套约定叫右手系，本章叉积一节要用它定方向。再认两门亲：其一，第 2 章缓冲区里 createTriangle 的 9 个浮点数，其实就是 3 个顶点向量接龙；其二，GLSL 早给向量留了户口——内建类型就叫 vec3，顶点属性（attribute）里声明的坐标就是它。第 1 章的渲染管线上，顶点着色器这个岗位每天搬运的正是向量。

三个数各管一根轴，还意味着「分量各自干活」。第 2 章渐变三角形里可变变量（varying）的颜色沿线渐变，就是光栅化硬件对 r、g、b 三个分量各自做线性插值——分量的独立性你已经见过，本章的加减法把它变成明规则。

加减与数乘：分量各自干活 ​

三种运算，几何意义各一句话。加法是接力：先走 a 再走 b，等效于直接走 a + b。减法算指向：b − a 得到「从 a 指向 b」的箭头，飞船的第一步就是它。数乘是拉长：长度乘 k 倍方向不变，k 是负数就原地掉头。

text
跟着算一遍：
接力：[1,2,3] + [4,5,6] = [5,7,9]（分量各自相加）
指向：目标 [4,5,0] − 现在 [1,1,0] = [3,4,0]
拉长：[3,4,0] × 2 = [6,8,0]；× (−1) = [−3,−4,0]（掉头）

「从 a 指向 b」还有个日常变体：两个点相减得到向量，反过来，一个点加上向量得到新点——位置加位移就是新位置。点和向量在存储上是同一个形状，区别只在你把它读成「地点」还是「走法」。

长度：勾股定理的第一笔账 ​

向量既然带着「走几步」，就得能量出步数。长度（length）的公式就是勾股定理推广到三根轴：三分量平方和开根。本章主教材 3-4-5 上第一笔账：[3,4,0] 的长度是 √(9+16) = √25 = 5——初中就认识的直角三角形。

有了长度，距离（distance）顺理成章：两点 a、b 的距离 = 先减出「从 a 指向 b」的向量，再量它的长度。distance([1,1,0], [4,5,0]) = length([3,4,0]) = 5，一笔账两用：方向和距离本来就是同一个向量拆出来的两份信息。

点积：方向一致度打分机 ​

这一节多花点笔墨——它是后续光照的地基。先看它为什么存在。

图形学里有个问题出现的密度高得惊人：这两个方向有多一致？光照是最典型的一问：一个面接住多少光，取决于表面朝向与光的方向的夹角——正对最亮，斜着打折，背光全黑。背面剔除问的是面朝我还是背我；反光问的是反射方向与视线齐不齐。图形学处处在问「这两个方向有多一致」。但「夹角」本身不好用：三角函数算起来贵，而且角度不能直接当亮度的乘数。我们想要一个数：同向给正、垂直给零、反向给负，夹角连续变化时它也连续变化。这个数就是点积（dot product）——打个比方：一台方向一致度打分机。

两向量的关系点积打分
同向正数，方向越齐越大满分
垂直恰为 0零分
反向负数负分

打分机的内部构造出奇地简单：分量两两相乘再求和。3-4-5 上跟一遍，并顺手把夹角和影子都算出来：

text
公式：a·b = ax×bx + ay×by + az×bz
跟着算：a = [3,4,0]（飞船方向），b = [1,0,0]（x 轴方向的单位向量）
a·b = 3×1 + 4×0 + 0×0 = 3
垂直检验：[3,4,0]·[−4,3,0] = −12 + 12 + 0 = 0
夹角：cos θ = a·b / (|a|×|b|) = 3 / (5×1) = 0.6 → θ ≈ 53.13°

为什么「乘出来再相加」恰好量出一致度？把 b 拆成两份：顺着 a 的部分，加垂直于 a 的部分。垂直那份乘出来贡献为零（上面 −12 + 12 的消法就是它在演示）；顺着那份就是 |a| 乘上 b 的影子长。所以 a·b = |a| × 影子长，夹角越齐影子越长，分数越高；交换 a、b 不影响这笔账——点积满足交换律，测试里专门断言了它。

影子值得单独给个名字。长度为 1 的向量叫单位向量（unit vector）——只留方向、扔掉大小的标准形态，书写时常在名字头顶加顶小帽记作 â，图形学里「只要方向」的场合一律先换成它。用单位向量当尺子去点积，读数就是影子本长：向量投影（projection）——a 沿 b 的方向压平后剩下的长度。演算两笔：[3,4,0] 在 x 轴的投影长是 3（读数恰等于 x 分量）；拿自己的单位向量 [0.6,0.8,0] 去量自己，投影长 5 = 自身全长。

点积把「夹角」压成了一个能直接当乘数用的分数。第 10 章的光照核心算式 N·L 就是点积：光的方向从统一变量（uniform）进片元着色器，与表面法线逐片元点积，正对光的面拿高分、斜面打折、背光面拿零分。着色器里 dot 是内建函数，本章实验场在 JS 里实现同名同义的那一个。

叉积：翘起的大拇指 ​

点积回答「多一致」，给了个数。另一类问题要的却是方向：同时垂直于这两个向量的方向是哪边？平面的朝向（法线）、旋转的轴、相机的「上」——都长成这个问句。回答它的是叉积（cross product）：a × b 生成一个同时垂直于 a 与 b 的向量，长度等于两个向量撑出的平行四边形面积。

方向交给右手定则：四指从 a 弯向 b（弯小角那边），大拇指的指向就是结果。

text
      y
      ↑
      │   右手定则：四指从 x 弯向 y，
      │   大拇指翘起指 z（朝屏幕外、朝你）
      +──────→ x
     ╱     轮换家规：x×y = z、y×z = x、z×x = y
    z（朝你）

打个比方：两张纸条十字交叉摆平，翘起来的大拇指就是答案的指向。由此还有一条脾气：交换顺序结果掉头（反交换），a×b = −(b×a)。3-4-5 上验一遍，顺便看面积从哪来：

text
公式：a×b = [ay×bz − az×by,  az×bx − ax×bz,  ax×by − ay×bx]
跟着算：a = [3,4,0]，b = [0,0,1]
a×b = [4×1 − 0,  0 − 3×1,  0 − 0] = [4, −3, 0]
长度 = √(16+9) = 5 = 平行四边形面积（底 1 × 高 5）

面积这条性质别急着背，记住它送的赠品就够：叉积为零向量 = 两向量共线（平行），撑不出任何面积。它后面的出场率高得惊人：三角形三顶点两两相减再叉积，就得到面的朝向——背面剔除按它判正反；第 7 章造相机时，视线方向 × 上方向 = 右方向，一次叉积定一根轴。

归一化：只留方向，扔掉长度 ​

工具凑齐，回来收飞船的账。痛点版错在把「混着距离的方向」当速度；修法是把长度剥掉。归一化（normalize）——向量除以自己的长度：方向原样保留，长度缩成 1，得到单位向量。

text
跟着算一遍：normalize([3,4,0])
长度 = 5，三个分量各除以 5
[3/5, 4/5, 0/5] = [0.6, 0.8, 0]
验算：√(0.6² + 0.8²) = √1 = 1   ← 长度恰为 1

修复版只多一次函数调用，位置挪了一下：

js
// 用法示例：修复版——先归一化，每帧走固定一步
const dir = normalize(sub(target, ship.pos))    // 只留方向，长度 1
ship.pos = add(ship.pos, scale(dir, SPEED * dt)) // 步长恒为 SPEED × 增量时间

归一化前，远近两艘飞船算出的方向长度不同（5 与 0.1）；归一化后都是 1——先归一化，再乘步长，速度与距离从此解耦。要不同速度就换 SPEED，要变速就把 SPEED 换成缓动曲线喂进来的值。

一个边界约定：零向量 [0,0,0] 没有方向可留。GLSL 里 normalize 遇到它是除以零，结果未定义；实验场把行为定死——返回 [0,0,0]，不抛异常。这是对真实规范的声明的简化：调用方拿到零向量，立刻知道「这一帧没有可走的方向」，自己决定原地不动还是换目标。

渐进实验：math/vec3 落进实验场 ​

老规矩，测试先走：tests/vectors.test.ts 先写好 19 条断言，此刻 src/math/vec3.ts 还不存在，跑 pnpm test 一片红（模块加载失败）；再实现模块让它们逐条转绿。数值全部纸笔可复算，3-4-5 是主教材。

ts
// tests/vectors.test.ts · length 的两条断言：3-4-5 对账与轴上长度
describe('length（长度：勾股定理）', () => {
  it('3-4-5 手算对账：length([3,4,0]) = √(9+16) = 5', () => {
    expect(length([3, 4, 0])).toBeCloseTo(5, 4)
  })

  it('轴上的单位长度：length([0,0,2]) = 2，length([0,0,0]) = 0', () => {
    expect(length([0, 0, 2])).toBeCloseTo(2, 4)
    expect(length([0, 0, 0])).toBeCloseTo(0, 4)
  })
})

模块本体 src/math/vec3.ts 分四段落进正文。第一段是类型与加减数乘——向量用 readonly 元组装，三个数，测试里直接写字面量：

ts
// src/math/vec3.ts · Vec3 类型与第一组：加减与数乘
/** 三维向量：x、y、z 三个分量。readonly——拿进来只读，出去给新数组。 */
export type Vec3 = readonly [number, number, number]

/**
 * 加法：两个走法接力——先走 a 再走 b，等效走法就是 a + b。
 * 分量各自相加。手算样例：[1,2,3] + [4,5,6] = [5,7,9]。
 */
export function add(a: Vec3, b: Vec3): Vec3 {
  return [a[0] + b[0], a[1] + b[1], a[2] + b[2]]
}

/**
 * 减法：b − a 得到「从 a 指向 b」的方向向量——算朝向的第一步。
 * 手算样例：目标 [4,5,0] − 飞船 [1,1,0] = [3,4,0]，指向目标。
 */
export function sub(b: Vec3, a: Vec3): Vec3 {
  return [b[0] - a[0], b[1] - a[1], b[2] - a[2]]
}

/**
 * 数乘：把向量的长度拉成 k 倍，方向不变；k 为负则掉头。
 * 手算样例：[3,4,0] × 2 = [6,8,0]（长度从 5 变 10）。
 */
export function scale(v: Vec3, k: number): Vec3 {
  return [v[0] * k, v[1] * k, v[2] * k]
}

第二段是两把量尺：勾股量长度、乘积和量一致度。

ts
// src/math/vec3.ts · 两把量尺：勾股量长度、点积量方向一致度
/**
 * 长度：勾股定理——三分量平方和开根。
 * 手算样例：length([3,4,0]) = √(9+16) = 5。
 */
export function length(v: Vec3): number {
  return Math.sqrt(v[0] * v[0] + v[1] * v[1] + v[2] * v[2])
}

/**
 * 点积：两向量方向的一致度——同向正、垂直零、反向负。
 * 分量两两相乘再求和。手算样例：dot([3,4,0],[1,0,0]) = 3+0+0 = 3，
 * 恰是 [3,4,0] 在 x 轴上影子的长度（单位向量当尺子时点积=投影）；
 * 夹角由 cos θ = dot(a,b) / (|a||b|) 读出。
 */
export function dot(a: Vec3, b: Vec3): number {
  return a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
}

第三段叉积。公式确实容易记混——记不住就回来查，右手定则负责方向，公式只负责分量：

ts
// src/math/vec3.ts · cross：右手定则的垂直方向
/**
 * 叉积：a × b 得到同时垂直于 a、b 的向量，方向按右手定则——
 * 四指从 a 弯向 b，大拇指的指向（右手系下 x×y=z）。
 * 长度等于 a、b 撑出的平行四边形面积（a、b 共线时为 0 向量）。
 * 手算样例：cross([3,4,0],[0,0,1]) = [4×1−0, 0−3×1, 0] = [4,−3,0]，
 * 长度 5 即两向量撑出的面积。
 */
export function cross(a: Vec3, b: Vec3): Vec3 {
  return [
    a[1] * b[2] - a[2] * b[1],
    a[2] * b[0] - a[0] * b[2],
    a[0] * b[1] - a[1] * b[0],
  ]
}

第四段是本章主角与它的搭档。注意 normalize 内部先量长度、除零之前先判——零向量走约定分支：

ts
// src/math/vec3.ts · 归一化与距离
/**
 * 归一化：除以自身长度，只留方向、把长度缩成 1——「每帧走固定一步」
 * 的前提。手算样例：normalize([3,4,0]) = [0.6, 0.8, 0]。
 * 零向量没有方向可留：按实验场约定返回 [0,0,0]，不抛异常——
 * 调用方拿到零向量即知「这一帧没有可走的方向」。
 */
export function normalize(v: Vec3): Vec3 {
  const len = length(v)
  if (len === 0) return [0, 0, 0]
  return [v[0] / len, v[1] / len, v[2] / len]
}

/**
 * 距离：两点先减出方向向量、再量它的长度。
 * 手算样例：distance([0,0,0],[3,4,0]) = length([3,4,0]) = 5。
 */
export function distance(a: Vec3, b: Vec3): number {
  return length(sub(b, a))
}

两根向量：点积 / 夹角 / 叉积方向

  • a·b = 0.75（同向正、垂直 0、反向负）
  • 夹角 θ = 60.0°，â·b̂ = cos θ = 0.50（先归一化再点积，分数只看夹角）
  • a×b 的 z 分量 = -1.30，方向朝屏幕里（背你）（弧箭头 = a 转向 b 的旋向）
  • |a| = 1.00，|b| = 1.50，影子长 = a·b / |b| = 0.50

飞船：归一化开关对比

  • 模式：忽快忽慢，实时速度 0.00 单位/秒，距目标 0.00
  • 关：速度 = 距离 × 1.5——离目标越远飞得越快，贴近后爬行（蓝点间距就是速度）
  • 开：速度恒为 1.5——先把方向归一化成单位向量，再乘固定步长

演示侧，按这个清单玩：

  • 面板一把 a、b 转到同向：a·b 最大；转到垂直（比如 0° 对 90°）：恰为 0；转成反向：负数——打分机全程连续，没有跳变。
  • 只拉长度滑杆不动角度：a·b 跟着变，â·b̂ = cos θ 纹丝不动——分数混着长度与夹角两件事，归一化后只看夹角。
  • 看蓝色影子段：a 在 b 上的投影，画面长度与「a·b / |b|」的读数吻合；影子为负时影子段落到 b 的反方向延长线上。
  • 叉积读数：z 为正时弧箭头逆时针、结果朝屏幕外（朝你）；转角度滑杆让它过零变号，方向说明跟着翻面。
  • 面板二默认关着归一化：出发猛、贴近爬，蓝色轨迹点由疏变密，速度条带是一根下坠曲线；打开开关重跑：速度条带贴着虚线走——每帧固定一步，痛点版与修复版同屏可切。
  • 飞船到达后停留片刻自动重置循环；切开关也会重置航程，方便来回对比。

小结 ​

图形世界的通用语集齐了。向量 = 三个数各管一根轴，装下「方向 + 长度」；减法算指向、加法接力、数乘拉长，分量各自干活。长度走勾股：[3,4,0] 的长度是 5，distance = 先减后量。点积是方向一致度打分机：同向正、垂直零、反向负，除以两个长度得 cos θ；单位向量当尺子时读数就是投影。叉积给垂直方向：右手定则定指向、反交换，长度是撑出的平行四边形面积。归一化剥掉距离：方向和距离，用之前想清楚要哪个——飞船的修复就一行，normalize 后再乘步长。

这八件套是后半本书的地基：矩阵的每一列就是向量，第 5 章的变换机器在它们之上搭建；光照的 N·L、相机的三根轴、法线与背面剔除，全是本章这三个运算的排列组合。
